# あの仕事の年収と一生 投稿案 v2（2026-11-02）

## 1. 目的と順番

投稿は、ショートの視聴者を LINE へ送る押せる入口にする。流れは、投稿 → UTAGE の登録経路 → LINE の6問の診断 → 案内ページ。

v2 で方針を替えた。本人「それで投稿見る習慣付けてアフィ投稿も」「投稿は直接アフィリンクでいいよ」に合わせ、投稿に限って PR を付けたアフィのリンクを置く。動画・概要欄・タイトル・サムネ・コメントには出さない。

順番は次のとおり。

1. プロフィールに LINE のリンクを置く
2. 投稿を週2本で始める
3. リンクができたらショートの説明文を直す

## 7. 回し方

- 本数：手順書 §12 の「投稿」のとおり（v1 の週2本から増やした）。
- 作り方：投稿を作る公式の API が見つからないので、Claude in Chrome で Studio の画面から予約する。ログインを自動化する形は採らない。
- 見る数字：UTAGE の経路別の登録数（YouTube投稿、YouTubeプロフィール、YouTubeショート、YouTube長尺）。投稿ごとの高評価とアンケートの票数。
- 判断の線（仮）：4本出して投稿経路の表示が0のままなら、1本あたりに時間をかけず、プロフィールとショートに戻す。

## 8. 分かっていないこと

- 投稿のリンクが実際に押せるか。
- 予約の▼の中身。
- 登録者7人の時に、投稿が何人に届くか。
- 表示6回が本人や試験の分か、外部の視聴者か。
- 表示から登録が0の理由。LINE の友だち追加の画面まで進めたかは UTAGE の数字では分からない。
