# あの仕事の年収と一生 投稿案 v1（2026-11-02）

## 1. 目的と順番

投稿は、ショートの視聴者を LINE へ送る押せる入口にする。流れは、投稿 → UTAGE の登録経路 → LINE の6問の診断 → 案内ページ。

投稿にアフィのリンクと PR は置かない。本人の方針「YouTube上ではPRしない。LINEで相談乗ったうえでそのうえで場合によってアフィリンク訴求」に合わせる。

順番は次のとおり。

1. プロフィールに LINE のリンクを置く
2. 投稿を週2本で始める
3. リンクができたらショートの説明文を直す

## 3. 使える機能（Studio で確認）

使える物：画像、画像形式アンケート、テキスト形式アンケート、クイズ、動画。一覧に「スケジュール設定済み」の欄があり、投稿ボタンに▼があるので、予約はできる見込み（中身は未確認）。

機能の利用資格は3段階すべて有効。投稿のリンクは押せる条件を満たす見込みだが、1本目を出して確かめる。

## 6. 投稿文

### 1本目 テキスト形式アンケート

先月の残業、どのくらいでしたか。

選択肢：20時間まで／21〜45時間／45時間より多い／数えていない

### 2本目 文＋リンク（1本目の3日後）

先日のアンケート、一番多かったのは「（最多の選択肢）」でした。

残業の長さだけでは、職場のきつさは決まりません。同じ30時間でも、残業代が出ているか、休みが取れるかで話が変わります。

LINE の6問の診断では、残業、年代、一番こたえたこと、今の状況を聞いて、次に確かめることを返します。主な職業の年収と、業界ごとの離職率の一覧も無料で受け取れます。

https://utage-system.com/line/open/m1FcpYY2zwWA?mtid=Cjpcd8R7IWj7

票数は書かない。1本目の答えが5票より少ない時は、1文目を消して2文目から始める。

### 3本目 クイズ

年収がほぼ同じ、看護師と自動車整備士。月の残業などが多いのはどっち？

選択肢：看護師／自動車整備士（正解）／ほぼ同じ

解説：自動車整備士が月15時間、看護師が月6時間で、約2.5倍の差でした（厚生労働省「令和7年賃金構造基本統計調査」）。

## 7. 回し方

- 本数：週2本。投稿は登録者に届くのが中心なので、増やす前に数字を見る。
- 作り方：投稿を作る公式の API が見つからないので、Claude in Chrome で Studio の画面から予約する。ログインを自動化する形は採らない。
- 見る数字：UTAGE の経路別の登録数（YouTube投稿、YouTubeプロフィール、YouTubeショート、YouTube長尺）。投稿ごとの高評価とアンケートの票数。
- 判断の線（仮）：4本出して投稿経路の表示が0のままなら、1本あたりに時間をかけず、プロフィールとショートに戻す。

## 8. 分かっていないこと

- 投稿のリンクが実際に押せるか。
- 予約の▼の中身。
- 登録者7人の時に、投稿が何人に届くか。
- 表示6回が本人や試験の分か、外部の視聴者か。
- 表示から登録が0の理由。LINE の友だち追加の画面まで進めたかは UTAGE の数字では分からない。
