## 1. 中身（何の話か）
- 長尺は、1つの場所（財布・玄関・台所・トイレ・寝室・かばん など）で、お金が逃げる NG を3〜5個並べる（§15）。ショートは、1つの小物か、1つの場所の NG 3つ（§5）。
- NG には、1つずつ「なぜ金運が下がると言われるか」の意味づけを付ける。使うのは気・五行・風水・仏教・縁起のどれか1つ。売れている金運の動画は「具体的な物＋意味づけ＋下がる/上がるの判定」の形をしている（okinu_content まとめ）。これが見た人の「学んだ感」になる。
- 「これはやっていいか」に先回りして1文で答える（質問の14%がこの形。例：通帳やカードは入れていいか、母の形見の10円玉は）。
- お金のかからない物・手元にある物で成り立つ話だけにする。高い財布・特定の商品を前提にしない。
- 言い方は場所によって分ける（v1.5 から）。
  - 題・サムネ・各 NG の見出しでは、判定の語を使ってよい（お金が逃げる・貧乏神が住みつく・運気が下がる・NG・要注意・やってはいけない・入れてはいけない）。
  - 本文の説明では、「昔から〜と言われています」「〜と考えられてきました」の距離を保つ。「必ず貯まる」「必ず破産する」とは言わない。
  - 効かなかった人を置き去りにしない一言を入れる。逆に「お金を呼ぶ力はわかりません」と自分で否定もしない（001v6 の弱い締めは却下された）。
- 当たり前の前提にしない。「使ったらなくなる」のような、言われなくても分かる話を謎にしない（001 の一万円札は崩すな は前提ごと却下）。
- 研究・統計・出典を並べない（視聴者にその需要は見当たらず、v2・v5 で却下）。数字を言うなら一次情報で確かめた物だけ。「9割が」のような作った割合も使わない。
- 同じ決まりを何度も言い直さない。生活の常識を金運として言い直さない。
- お金の助言（貯金・投資のすすめ）にしない。習慣・言い伝えの話にとどめる。
- 使わない語：宝くじ・億・借金・一発逆転・今夜・今日・N秒以内に。「放置すると悲惨な老後」のような暮らしへの脅しも使わない。
- 「破産」は題・サムネ・見出しで使ってよい。「破産する家の特徴」の形も、「〇〇してる人は破産します」と言い切る形も使う（競合の上位サムネ15枚のうち6枚が「破産します」型）。本文の説明は上の「言われています」の距離で話す。
- 主人公は視聴者と同年代の女性（さわこ・すみえ）。夫婦や男性が主役の回は伸びなかった側に多かった。物語は、NG ごとの短い場面に使う。全体の4分の1までにする（§15）。

## 2. 冒頭（フック）
- 長尺の最初の40〜70秒は §15 の「冒頭の型」で作る。結論を先に見せる（丸儲け住職の形）。
- 1文目は、見ている人の家か財布にある NG を、目に見える形で言う（例：「財布の中に、レシートを入れたままにしていませんか。」「台所の湯のみに、小銭をためていませんか。」）。挨拶・名乗りから入らない。
- 5秒以内に判定を言う（例：「金運の世界では、それはお金が出ていく家のしるしと言われています。」）。
- 15秒までに「これから5つの NG を話す。いくつ当てはまるか数えながら見て」を1文で言う。見る人が指を折って数える仕掛けが、最後まで見る理由と学んだ感になる。予告はこの1文だけにする。
- 金額と年齢は早めに1つずつ（「年金11万円」など）。数字の種類を増やさない（v6 冒頭の失敗：金額4種類で追えない）。
- 何が言いたいかを1文で言える状態にしてから書く（「お金が出ていく台所には、この5つがある」）。言えないなら、まだ書かない。
- 中身の無い引っ張りを書かない（check_script.py が NG にする）：「答えは最後に」「このあとお伝えします」「後半でお話しします」「最後まで見てね」。ランキングの「第1位は、ほとんどの人がやっています」のように、中身のある予告はよい。§13 の長尺へつなぐ1文（日付と時刻）は導線なので残す。
- メタ文は、上の「いくつ当てはまるか数えて」の1文のほかは書かない（「今回は〜お話しします」「この動画では」）。
- 名乗らない（参考はどれも名乗り0）。
- 長尺だけ：全体の40%より前に、後半で答える問いを1つ置く（§15 のクイズ）。答えは後半で必ず出す。script.json では、問いのカットに "tease": true、答えのカットに "payoff": true を書く（check_script.py --long が位置を見る）。

## 3. 台本の書き方
- 淡々と流さない（v1.5 から）。次の4つを必ず入れる。
  1. 順位か番号（「第5位」〜「第1位」か「NG 1」〜「NG 5」）。新しい NG に入るたびに、画面いっぱいの番号カードを出す（§6）。
  2. 判定の言い切り（見出し）と、意味づけ（説明）を分ける（§1）。
  3. 1つの NG の中で、いちばん「へえ」となる1文（意味づけの意外な所か、「やっていいか」の答え）。
  4. 1分に3つ以上の新しい情報（物の名前・方角・色・数・やり方）。参考の真ん中の値が1分に約3.0個で、001v4 は1.05個だった（okinu_ref5 まとめ）。
- 1文は短く（ショートは平均20字前後、長くても27字）。1文に絵1枚。1カットは4〜6秒が目安。
- 数え方は「第〇位」「1番／2番／3番」「最初は／次に／そして」。「ひとつめ」は VOICEVOX で「いつつめ」に聞こえるので使わない。
- 締めはしんみりまとめない。チェックの数を聞く問いかけ（「あなたは、いくつ当てはまりましたか。」）か、すぐできる一言で終える。
- 禁止記号（── — → … ※ ★、水平線）を台本に入れない。
- 掛け合い・聞き役は入れない（コメントで嫌われる）。おきぬの1人語りと、登場人物の場面。
- 登場人物のセリフ（佐和子・澄江などが口にする言葉）は、おきぬの声のまま読まない。セリフだけのカットに分け、その人の声で読む（§4）。
- 物語は作り話なので、台本に `"fiction": true` と `"world_rules"`（誰が何を知っているか）・`"world_terms"` を書き、check_script.py が出す一覧を1つずつ照らす。
- 見どころ：1本に1つ以上、いちばん「へえ」となる場面に `"peak": true` を書き、動く絵か真ん中のキーワードカード（§6）で目立たせる。長尺は第1位の答えを peak にする。

## 4. 声と読み
- 声：VOICEVOX 波音リツ ノーマル（id 9）。
- 長尺の速さ（v1.7）：VOICEVOX の速さ 1.0 で作り、組み立ても 1.0倍（script.json `"tempo": 1.0, "gap": 0.3`）。めやすは1分に320〜340字。003 で測った値：1.2倍は1分393字（速すぎ）、1.0倍は1分331字（声の合計 633.1秒・3741字）。金運の参考20本の真ん中が1分333字、1人で解説する形は255〜351字（okinu_content まとめ・okinu_av まとめ）。前は v1.5〜1.6 の 1.2倍、その前は速さ 0.85＋1.1倍。
- 動くカード（motion_cards）を書き出す時も、台本と同じ `--tempo 1.0 --gap 0.3` を付ける（付けないとカードの長さが声と合わない）。
- 尺が足りない時に、声を遅くしたり間を広げたりして伸ばさない（間 0.35→0.45 の水増しは反省点）。
- 読みの表：金運おきぬ\yomi.json（replace＝声の文だけ置き換える／dict＝エンジンの辞書）。見つけた誤読はここに1行足す。
- 点検は声を作る前に、全カット：
  `python -X utf8 C:\yt-auto\pipeline\yomi_auto.py <作業フォルダ> --speaker 9 --yomi "<金運おきぬ\yomi.json>"`
  食い違いが出た語を1語ずつ見て決める（辞書の方が間違う語もある：1万→イチイチマン、1分→フン など）。助詞の「は」をハと読む誤りもこれで出る。
- VOICEVOX は同じ語でも前後の文で読みが変わる。表に入れた語も毎回点検する。
- 字を見て危ない語：米・家・帰す・上・方・角・母・札（札は／札を／札が の後が崩れる）・人名・「第〇位」（v1.5 で増えるので、初回に読みを確かめる）。登場人物の名前は読みが1通りの名前にする。
- 声を作ったら、通しで1回聞く（本人に指摘されてから気づく、をやめる）。

## 13. ショートから長尺へ人を送る（2026-10-28 から）
ショートは新しい人の入口、長尺は見続けてもらう場所。役割が違うので、数字は別々に比べる。長尺1本につき、長尺へつなぐショートを3本前後作る。ほかの日は、1本で言い切るショート（§5）。
- 種類：
  - 予告：長尺の公開の前（48時間以内）に出す。長尺の NG を1つか2つ出し、第1位の手前で止める。長尺へつなぐ1文は「第1位は、10月31日夕方6時の長い動画で。」のように日付と時刻で言う（今日・明日・今夜は §1 のとおり使わない）。
  - 切り出し：長尺の公開の後に出す。長尺の NG を1つ切り出し、意味づけの一歩手前まで。つなぐ1文は「続きは、チャンネルの長い動画で。」
  - 単独：1本で答えまで言い切る（§5 の型）。長尺へは概要欄だけでつなぐ。
- 予告と切り出しも §5 の型の1文目と最初の文字を守る。長尺へつなぐ1文は、締めの問いの直前に置き、最後は問いで終える（コメントを集めるため）。
- 同じ問い・同じ答えを、2本のショートで使わない（§12 の2）。
- 日付を声で言うショートは、長尺の予約を先に固めてから声を作る（長尺の日を動かすと作り直しになる。アナザー日本紀で起きた）。
- 絵：長尺の絵を縦に置き直して使ってよい（`landscape_to_portrait.py`。使い方はアナザー日本紀の制作ルール §8）。置き直した絵は1枚ずつ見る（§6）。置き直したショートの字幕が小さく見える件は、改善ログの「次に上げること」に残っている。
- 作業フォルダ：予告は `S番号_予告_〇〇`、切り出しは `S番号_切出_〇〇`。単独は `S番号_〇〇`。
- 概要欄：1段落目のすぐ下に「本編（長い動画）：<URL>」。台本では {LONG_URL} と書いておき、長尺を上げた後に URL を入れてから上げる。長尺は、つなぐショートより先に予約しておく。
- 長尺が公開されたら：ショートの「関連動画」に長尺を付ける（API ではできないので Studio で）。ショートのコメント欄に長尺のリンクを入れるのは、長尺の公開の後。見張り（watch.py）は okinu を見ていないので、コメントは自動では入らない。
- 数字：長尺の「トラフィック ソース」で、ショートから来た人がいるかを Studio で見る。ショートは種類ごとに、再生・平均視聴率・登録を並べる（2本以上ある物だけ比べる。スキルの 09・14）。
