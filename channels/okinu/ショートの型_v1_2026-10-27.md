## 型（1本 約35〜40秒）
| 項目 | 決めること |
|---|---|
| 題材 | 1本に小物か行為1つ。毎日変える（財布・家・毎日のくせを回す） |
| 長さ | 270〜300字・15文前後・1文平均18〜19字（最長26字） |
| 1文目 | 「〇〇を、〜していませんか。」見た人が自分の財布を確かめる問い |
| 2〜5文目 | 主人公（すみえ・さわこ）の場面と「〜のに〜」。年齢・金額は出すなら1つずつ |
| 6〜8文目 | 言い伝えと、そのわけ（「昔から〜と言われています」） |
| 9〜12文目 | 「やっていいか」への答えと、手元の物でできるやり方1つ |
| 13〜14文目 | 主人公のその後。効いたと言い切らず、暮らしで見えた変化（何に使ったか見える など） |
| 最後 | 「あなたの〇〇には、〜ですか。」で終える。コメントがその答えになる |
| 画面いっぱいの文字 | 最初の1〜2秒、5字×2行まで（「レシート／入れてる?」） |
| 絵 | 縦 1080x1920。1枚で2文ほど、1本7〜8枚。物（財布・お札・カード）の寄りを中心に、おきぬは最初と最後だけ。字はセーフゾーン（横48〜888・縦288〜1248）の中 |
| 声 | 波音リツ（id 9）。速さは1本目で2通り作って本人に聞いてもらって決める |
| 音 | 効果音なし。BGM は長尺と同じ物を声より25dB以上下げる |
| 題 | 20字前後。自分で確かめる形か「〜の人へ」。【60代】などの年代を頭に。言い切らない |
| 説明 | AI で作っていること・VOICEVOX:波音リツ・物語は創作であること。タグは #shorts と2つまで |
| 固定コメント | 最後の問いを、そのままもう一度 |

使わない形：「絶対〜しないで」「入れてはいけない」の脅し寄りの言い方（伸びた題に多いが、制作ルールの「脅さない」とぶつかる）。代わりに「〜していませんか」で同じ「自分の財布を確かめたくなる」を作る。
