- 使うずらし方は7つ（2026-10-27 に「もしも」系の動画716本の題から分けた。数字は記録.md）。

  3. 制限：何かが禁止・不可能になる
  4. 翻訳：歴史の出来事を今の道具の形で見せる（関ヶ原がグループLINE）
  5. 時代ワープ：今の仕事の人が昔へ行く（消防士が江戸の大火、コンビニ店員が江戸）

## 3. 1本の型（ショート）
1. 1秒目：画面いっぱいの文字（hook）＝何をずらしたか。1行5字・2行まで。
   - 声の1文目（1秒目の決まり。2026-11-05 本人「この動画を見ると何が得られるのか（結論・ベネフィット）を1秒目から出すこと」。書き手 `write_script_nihongi.py` と台本ゲートも同じ）：「もしも＜ずらしたルール＞たら、＜史実の誰・何＞はどうなったか。」の形か、結果を言い切る文にする（何が見られる動画かが1文目で分かる）。ずらしたルールだけを言う1文目は不合格。年・場所・場面は2文目から。画面の hook と同じ文にしない。
2. 上の帯：大きい文字＝チャンネル名「アナザー日本紀」、小さい文字＝意外な結果（10字まで。例「光秀だけ99%」）。帯は最後まで出しっぱなし。
3. 本編：場面を3つ前後。どの場面にも、本当にあった出来事（年・人・場所）を1つ入れる。ここが「へえ」の元。
   - 流れは1本道（2026-11-07 から）：もしも → 作り話の世界を最後まで通す → 最後に1回だけ「実際は〜」。本当にあった出来事は、作り話の世界の背景として同じ語り口で言う（「1657年、明暦の大火。」のように）。途中で「本当は」「実際の歴史では」「史実では」と現実に戻って、また作り話に戻る、を繰り返さない。現実へ切り替えるのは1本に1回、オチのあとだけ。
4. オチ：最後の場面で、ずらしたルールのせいで史実が少しだけひっくり返る。
   - オチは、絵を見れば分かる結果を1つ（誰が何をした・何が残った・何人が助かった、のような形）。和歌・辞世の句・遺言・史料の一文を知らないと笑えない・驚けないオチは使わない（使うなら言葉の意味をその場で言い、それ無しでも結果が分かる形にする）。オチを2つ3つ重ねない。
   - オチのあとに「実際は〜」を1文だけ置いてよい（本当の結果を言うと「へえ」が強くなる）。この1文が、1本の中で現実へ戻る唯一の所。
   - 見どころ：1本に1つ、いちばん面白い場面を決めて、そのカットに `"peak": true` を書く（多くはオチか「1人だけ異常値」の場面）。動く絵（§5）に、highlight か寄りを足して目立たせる。ほかの回と同じ見どころにしない。
   - 人物のセリフ：入れてよい（掛け合いは入れない）。セリフはセリフだけのカットにして、その人物の声で読む（§5 の声）。
5. 締め：決まった一言「あなたなら、どこで歴史を変える？コメントで教えて。」（毎回同じ）

## 4. 史実と作り話の分け方
- 年・人・場所・出来事は本当の物だけ。台本を書く前に調べ、出どころを script.json の `facts` に残す。
- ずらしたルール（確率・LINEの文・刀の声）は作り話。概要欄に「※〇〇は作り話です。出来事は史実をもとにしています。」と書く。
- 説や逸話（平蜘蛛、小豆袋、「敵は本能寺にあり」など）は、史実のように言い切らない。使うなら「〜と伝わる」。
- ずらしたルールは、台本に `"fiction": true`・`"world_rules"`（誰に何が見えるか・誰が何を知っているか、を1行ずつ）・`"world_terms"`（決まりに出る言葉。例 ["数字", "%", "札", "確率"]）を書く。`check_script.py` が決まりに関わるカットを全部出すので、1つずつ「その人はそれを見られるか・知っているか」「語り手の文か、人物の文か」を照らす。
  - 実例（2026-10-28 本人の指摘）：「数字が見えるのは信長だけ」なのに、信長が自分の頭の上の数字を見る話（S002、L001 の F01・I11〜I14）、秀吉が自分の数字を知っている前提で答える話（S004、L001 の H09b〜H10）を書いた。直し方：自分の頭の上は見えないので、答えは語り手が出す（「信長には見えない、自分の頭の上。もし見えたなら、」）／信長は数字を口に出さず心の中で思うか、数字に触れない問いにする（「お前は、なぜ一度もわしに背かぬ」）。
- 使わない題材：実在の人の性・病気・民族を笑いの種にする物、今も生きている人や今も遺族・関係者がいる近現代の事件（昭和の戦争は、下の「昭和の扱い方」を守って扱う）。
- 昭和（戦争を含む）の扱い方（2026-11-12 から。本人「昭和も扱っていこう」）。1つでも外れた回は出さない（§10 の7）：
  1. 笑いにしない：戦争の死者・被害・戦場を、笑い・ツッコミ・軽い言い方（「ヤバすぎた」「詰んだ」など）の種にしない。語り口は落ち着いた調子にする。
  2. 美化しない：「最強」「無双」「圧勝」「スカッと」のような、戦争や勝ち負けをたたえる言い方を、題・サムネ・声のどこにも使わない。最後の章の良い未来（§7）は「日本が勝った」ではなく、助かった命・続いた暮らし・残った町にする。
  3. 小さく言わない・無かったことにしない：日本が受けた被害も、日本がほかの国に与えた被害も、出どころのある事実を減らしたり否定したりしない。分かれ道より前の史実は変えない（§7 の1点だけ）。
  4. むごい絵を出さない：血・遺体・焼けた人・きのこ雲の寄り・拷問・処刑の場面を、絵・動く絵・サムネに出さない。被害は、出どころのある数字と、残された物（焼け跡・手紙・空になった家・名簿）で伝える。
  5. どの国の死者も同じ重さで扱う：日本の死者だけを数えない。相手の国の人を見下す呼び方・当時の差別語を使わない。当時の呼び名が要る時は1本に1回まで、「当時の呼び名で」と断って言う。
  6. 数字と出来事の出どころ：死者数・被害の数・日付は、公的な出どころ（国立公文書館・アジア歴史資料センター・厚生労働省・平和祈念展示資料館・防衛研究所の公開資料・各自治体の資料など）で確かめ、script.json の `facts` に出どころを書く。死者数は「〜とされる」と出どころを付けて言い、説が分かれる数は幅で言う。
  7. 昭和天皇：記録に残る言葉・出来事の範囲だけで出す。作り話のセリフ・心の声は書かない。
  8. 国どうしで今も争いのある題（慰安婦・南京事件・靖国神社の参拝など）は、主役の題にしない。流れで触れる時も、出どころのある事実を1文だけにする。
  9. 広告に合わせる：題・サムネに「地獄」「全滅」「皆殺し」「惨殺」などの言葉を使わない。サムネに爆発・炎・遺体・旭日旗・ナチスの旗を出さない。サムネの絵は人物の真剣な顔か、町・船・地図にする。
  10. 概要欄：戦争の回は、作り話の断り（§7）の下に「戦争で亡くなられたすべての方に、哀悼の意を表します。」を1行書く（毎回同じ文）。
