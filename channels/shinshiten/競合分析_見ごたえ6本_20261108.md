# 競合分析: 見ごたえのある6本 vs 京アニ回 full_v7b（2026-11-08）

## 結論

1. 差の一番大きいところは「動かし方」ではない。**台本が「主張と反転」で進むか、「出来事の年表」で進むか**の差と、**絵が「その一文の意味を演じている」か、「雰囲気の背景に文字を乗せている」か**の差。
2. 動きの量とカットの速さは、うちの方がむしろ多い（下の実測）。いくら動かしても、絵の意味が変わらなければ見ごたえにはならない。
3. 技術的にできないことはほぼ無い。台本の書き方は今すぐ変えられる。絵の作り方は、画風の固定と、カットごとの「たとえ絵」の設計という手間を足せばできる。手で作った3DCG並みの絵を毎カット出すことだけは、今の道具では安定しない（推測）。

1本の流れは「過去の空想 → 過去の現実 → 今 → 近い未来 → あなた」。話がだんだん見る人に近づいてくる。うちの京アニ回も最後に問いを残している（「ためらいと、その一歩のあいだに、何があったのか。その問いは、今も残っている」）。ただ、問われているのは青葉で、見る人自身ではない。その直前の12カット（H13〜H24b）は、判決と控訴の手続きが続いていて、話が見る人から遠ざかったまま終わる。

**うちの台本に足りないもの（要約）**
- 1本を通す「主張」が無い。「ためらった男がなぜ火を放ったか」は冒頭と最後にあるが、途中の章がその答えに向かって進んでいない。
- 事実の確認の言い回しが多く、語り手が考えを言わない。e8v は事実を並べた後に「これが意味することは何だろう」と毎回まとめに行く。

## 3. できるか・できないか

| 要素 | 判定 | 理由・やり方 |
|---|---|---|
| 主張と反転で進む台本・言い切る語り・たとえ・「我々」の巻き込み | 今すぐできる | 台本の型を変えるだけ。事実の確認は概要欄の出典と、本編の要所の一言に寄せる |
| 矛盾を置いて問うタイトル・中身を想像させる章タイトル | 今すぐできる | 同上 |
| 画風を1本で固定 | 手間をかければできる | 画像生成に「画風の指定文」と見本画像を毎回付ける。Lovart の無料枠が11/16まで0なので、当面は別の生成手段か枚数の節約が要る |
| 同じ主人公を出し続ける | 手間をかければできる | 人物の見本画像を指定して生成する。顔を出さない後ろ姿にすると、ずれが目立ちにくい |
| 1文ごとのたとえ絵 | 手間をかければできる | 一番効くが一番手間。カットごとに「この文を絵で演じると何か」を台本の段階で決める。数字は生成した絵の上に PIL で重ねる（絵に文字を描かせると崩れるため） |
| 実際の写真・地図・資料 | 今すぐできる | ネットの写真・古地図は使ってよい決まり。出どころのURLは記録する。ただし京アニ回では亡くなった方の写真は使わない |
| 写真の奥行きを出すカメラ（2.5D） | 手間をかければできる（推測） | 1枚の絵から奥行きを推定して、手前と奥を少しずらす。この PC で回る速さかは未確認 |
| アニメ本編の画面の引用（r8e 型） | やらない方がよい | 著作権の面で危ない。チャンネルが消えると全部無駄になる |
| 手作りの3DCG（大和の模型のような絵）を毎カット | 安定しない | 1本に数か所なら、生成画像＋奥行きで近い絵は作れる（推測） |

## 4. 次に上げること（優先順）

1. 次の回の台本は「1本の主張」と「3つの問い→答え」を先に決め、章ごとに「常識→裏切り→まとめ」を1回入れる。
2. 画風の指定文を1つ決めて、1本まるごと同じ画風で作る。主人公（後ろ姿）を1人置く。
3. カット表に「この文を絵で演じると何か」の列を足す。雰囲気だけの背景は全体の3割までにする。
4. 締めは、判決や事実の整理で終わらせない。「あなたが同じ場所にいたら」という、見る人自身への問いで終える。チャンネルの決まり文句を1つ作り、毎回最後に入れる。
