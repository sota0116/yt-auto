## §0 名前と出し方
- チャンネル名：シン視点事件簿
- 中身：実際の事件を、犯人（判決前なら容疑者・被告）の側から順にたどる。悪者として片づけずに、どこで分かれ道があったかを見る
- 出す物：長尺だけ。週1〜2本（仮の枠は 水・日 の 21:00。競合の公開時刻をまとめたら決め直し、決めたら当分動かさない）。ショートは型だけ決めた（§8）。枠と始める日は持ち主のOKのあとに入れる。それまでは作らない・上げない
- 作り方：フルAI（台本 Claude、声 VOICEVOX、絵 AI＋報道写真）。投稿は自動予約。ただし1本目と、型を変えた最初の回は持ち主のOKのあとに出す
- 英語版は作らない

## §1 誰に向けるか
- 事件のニュースを見て「なぜそうなったのか」が気になったまま終わった人。ワイドショーの怒りや断罪ではなく、筋道を知りたい人
- 見る理由：その人がどんな道をたどって事件の日に至ったかを、記録に基づいて順に知れる。報道では切れ切れだった話が1本でつながる
- 持ち帰る物（電子ゴミの線 1）：分かれ道になった出来事と時刻、法廷で何が争われたか、専門家がどう見たか、のどれかが毎回ある

## §2 企画（題材の選び方）
- 決め方は「伸びるかどうか」だけ（2026-11-06 本人）。有名な事件・最近の事件・最近思い出された事件（判決・逮捕・再審・節目の年）
- ネタ帳.json の rows を上から。節目（判決の日・逮捕の報道・事件から○年）が近い物を先にする
- 公判中・起訴前の題材は、書く直前に今どこまで決まっているかを報道で確かめ、ネタ帳の note に日付つきで書く
- 同じ犯人を2回扱わない（続編は、新しい判決・再審が出た時だけ）

## §3 型（長尺の台本）
章の順番は固定。章の中身と山場だけを毎回変える。

| 章 | 中身 | 目安の比率 |
|---|---|---|
| 冒頭（約45秒） | 衝撃から入る：黒地に犯人の法廷の言葉1行（赤字の語あり）→ 事件当日の本物の写真（燃える建物など）→ 被害の数字（例 死者36・負傷32）→ 問い「なぜ」→ 題名カード → 1章へ。挨拶・名乗り・「この動画では」の説明はしない | 5% |
| 1 生い立ち | 家族・育った土地・学校。記録に残る出来事だけ | 12% |
| 2 つまずき | 仕事・人間関係・お金。最初の分かれ道 | 12% |
| 3 心の動き | 本人の供述・書き残した物・精神鑑定で分かったこと。犯罪心理学の見方 | 12% |
| 4 その後の環境 | 孤立・転居・最後の分かれ道。「この決断が○○の人生を大きく分けることに」 | 10% |
| 5 準備 | 下見・持ち物をそろえた日付・前日の動き | 10% |
| 6 事件当日の手口 | **いちばん長い章**。時刻ごとの動き（分単位）、建物の作り、法廷の供述、止められた瞬間・捕まった瞬間 | 22% |
| 7 法廷と世の中 | 判決・争点・専門家・メディア・世論の見方。未解明の点 | 10% |
| 8 終わり | IF は入れない（v5〜）。法廷か治療の場で本人が口にした言葉 → 答えの出ない問いを1つ → 慰霊の場所（銘板・献花）の写真に追悼の一行 → 無音で終える。まとめの説明・次回予告・登録のお願いはしない | 7% |

- 6章に入れる物：下見の日と回数、準備の物と買った日（品名まで。量・配合・作り方は書かない）、時刻ごとの動き、建物の間取り・出入り口・逃げ道（報道と判決で出た範囲）、本人の供述、周りの人の動き、止められた・捕まった時の様子
- 6章に入れない物：まねできる手順（量・配合・着火や凶器の使い方・見つからない方法）、むごい絵、被害者一人一人の最期
- 分かれ道の演出：「この決断が、○○の人生を大きく分けることになる」を2〜3回まで。乱発しない
- 山場は3つ置く（v5〜）：約30%（最初の分かれ道や思い込みが固まる所。黒地の言葉カード）／約65%（事件直前のためらいの時間。犯人の短い独白）／約85%（法廷。法廷画＋最終陳述＋遺族の言葉は文字で）。山場の前後で絵の切り替えを速くする（§5-2）
- IF（「もしこの時〜だったら」）は入れない（v5〜。競合14本のどこにも無い）
- 聞き手（kikite）は、見ている人の疑いを口にする役（v8〜）。形は「待って、じゃあ○○は？」→ 語りが記録で答える → 聞き手がもう一度だけ受ける（「…それで止まらなかったのか」など1文）。章に2〜3回（仮の数。002 の数字を見て決め直す）。6章（事件当日）は0〜1回にして語りで押す。冗談・茶化し・ツッコミの笑いは入れない。立ち絵キャラは画面に出さない（実録事件の競合14本で掛け合いがあるのは1本だけなので、ここは試しの扱い）
  - v7 までは「短い問いだけ・章に1〜2回」だった。問いを出しても答えと受けが無いと、見ている人の疑問が置き去りになる（視点系3chの比較。伸びている ch1 は問い→答え→受けが続く）
- 犯人の言葉は、基本は黒地の言葉カード（白字。脅し・決定的な語だけ赤）。声（hannin）で読むのは山場など数か所だけ（1本で3〜6カット）。供述・手紙・書き込みなど記録に残る言葉だけで、言い回しは要約してよいが中身は足さない
- 記録の声（kiroku）は v5 では語りと同じ声で読む（2026-11-07 持ち主が選んだのは語り・聞き手・犯人の3つ。kiroku の声は選ばれていないので、語りの声にまとめた。仮の決め）
- スキルの決まりはそのまま：check_script NG 0件、"anim":"kling"（か card）を章の数＋1以上、"peak": true を1つ（6章に置く）、伏線は40%より前・回収は後ろ、登録の呼びかけは入れない（v5〜。スキルの既定より持ち主の指示が優先）、「続きが気になる人は」などの引っ張りも禁止、冒頭に挨拶・名乗り禁止
- 長さは目的にしない。中身が尽きたら終える（8分未満でも、門を通れば出す）
- 場所の言葉は、見ている人が絵を見ずに分かる語にする（v6〜）。「玄関」「現場」「そこ」のように、どの建物のどこか分からない語は使わない。「スタジオの正面の入り口」「1階の受付の前」のように、建物の名前と場所を言う。2回目からは「入り口」でよい（001 v6 で「玄関に向かったのか」が意味不明と言われた）

### §3-2 問いとひっくり返し（v8〜。視点系3chの比較から）
伸びている回は「難しい話」ではなく「問い → 記録で分かった意外な事実 → 答え」が短い間隔で続く。深く見せようとして言葉を難しくしない。
- 3つの問いを先に決める：台本を書く前に、この回の「1本の主張」と「3つの問い」を事実メモの下に書く（例「なぜ京アニだったのか」「止められる所はあったのか」「法廷で本人は何を認めたのか」）。冒頭の「なぜ」のあとで3つを短く約束し、7〜8章までに全部答える。答えられない問いは「分かっていない」と言って閉じる（埋めない）
- ひっくり返し：章ごとに「問い → 報道で思われていたこと → 記録（判決・供述・報告書）で分かった違う事実 → 答え」を最低1回。1〜2分に1回、見ている人の思い込みが動く所を置く。ひっくり返す事実は事実メモにある物だけ。驚かせるために事実を曲げない・順番を入れ替えて誤解させない
- 中身の予告：1本に2〜3回、「この十数分は、あとで法廷でもう一度出てくる」のように、あとで回収する中身を先に言う。予告1つに回収1つ。カット表に「予告のカット id → 回収のカット id」を1行ずつ書き、回収の無い予告は消す。「続きが気になる人は」「このあと衝撃の」のような中身の無い引っ張りは禁止のまま（§3）
- 章の題：「生い立ち」「つまずき」のような分類名にしない。その章でいちばん目に浮かぶ出来事を、事実メモにある言葉で短く書く（年齢・物・場所のどれかを1つ入れると想像しやすい）。事実メモに無い出来事で題を作らない。あおり（「狂気の」「衝撃の」）は入れない
- 終わりは冒頭の1行に戻る：8章の「答えの出ない問い」は、冒頭の犯人の言葉か3つの問いの1つに戻して閉じる

## §4 事実と推測の分け方
- 使う元：判決文・裁判の報道（大手紙・NHK・通信社）・本人の手記や公開された文書・公的な報告書。まとめサイト・掲示板の噂は使わない
- 書く前に事実メモを作る（例 crime/facts_kyoani.md）。1行に1つ、元の記事を添える。台本の事実はメモにある物だけ
- 言い方の線：
  - 判決で認められた事実 → 言い切ってよい
  - 本人の供述 → 「〜と供述した」「〜と話している」
  - 検察・弁護側の主張 → 「検察は〜と主張」
  - 専門家の見方 → 名前か肩書き＋「〜とみる」
  - 分からない事 → 「分かっていない」と言う。埋めない
- 判決前の人：「容疑者」「被告」を付け、事実は「〜とされる」。有罪と決めつけない。概要欄にも「裁判は続いています」と書く
- 「真実は」「本当の動機は」と言い切らない（禁止表現.txt）
- 断りの言葉の量（v8〜）：判決で認められた事実まで「報じられている」「とされる」で包まない。001 は約6,020字で「報じられている」17回＋「とされる」9回（1000字あたり約4.3回）あり、話が遠く聞こえた。目安は1000字あたり1回以下。断りが要るのは判決前の人のことと、供述・主張・見方だけ。出どころは語りで毎回言わず、概要欄にまとめる。上の言い方の線（判決前は言い切らない）は変えない
- 概要欄に「セリフは記録をもとにした再現です」を入れる（本編の画面・語りには出さない。v4〜 持ち主の指摘：メタ的なことは言わない）

  - 概要欄：本物は「※法廷画（報道より引用）」の節に局名と記事 URL、「法廷画は一部を切り抜いています」。AI は「法廷の絵は記録をもとにした再現イラスト」
  - 報道の法廷画は引用の形で使う。公開してよいかは持ち主が決める（Claude は投稿しない）
- 人物の図解（v6〜）：人はピクトグラム型の図（丸い頭と体の形）で描き、ネオンの光で男女を分ける。**男性＝青、女性＝赤**。子ども（age: child）は小さく、医師は白衣、弁護士・検察・学者はスーツ（outfit）。名札は図の下に付ける。顔のない線画の人影（v6 までの sil）は使わない
  - カードの sil 要素に "gender": "male"|"female"・"age": "adult"|"child"・"outfit" を必ず書く
  - 名札と字幕を重ねない（名札は y 820 より上）
- 背景の絵と重ねる物の決まり（v6〜）
  - 背景に絵・写真があるボードは、背景をぼかさずに見せる（board3）。その上に人物の線画・図解を載せない（001 v6 で「背景画像に線画が入って見れない」）。人を見せたい時は、背景を無地にして図解だけにするか、写真の額だけにする
  - 背景の絵にすでに文字（時刻・数字・「十数分」など）があるカードには、同じ文字の札・アイコンを重ねない。足すなら絵の文字がない所へ
- 火災の回（v6〜）：火が出る・火を放つ・燃え広がる場面の図解には火を描く（カードの fire 要素）
  - kind "ambient"：画面のふちが赤く揺れて火の粉が舞う（火が出た時刻から）
  - kind "flame"：建物の断面・間取りの中で、燃えている場所に炎を立てる（x0〜x1・y・h、layer は絵の下 under か上 over）。燃え広がる時は 2つ目の flame を "at" を遅らせて大きく出す
  - 燃える人・やけどの描写はしない（§5 の絵の決まりのまま）
- 主役は本物の写真（事件の場所・当日・逮捕時・裁判所・慰霊の場所）。AI の絵は場面のつなぎだけにする。文字の図解カードは人物カードと年表の札くらいまで減らす
- 地図・時刻表・間取りは card（動く図）で作る。6章の時刻ごとの動きは、時計と地図のカードを中心にする
- 1本ごとに、全カットの1コマを1枚に並べて Claude が見る（文字切れ・同じ絵の連続・むごい絵が混ざっていないか）

### §5-2 見せ方の型（視点系の競合から。2026-11-06 測定）
参考：夜ふかし考察部（@yofukashi-kousatsu・中央値 7.9万再生）を主、裏視点（@ura-shiten）・studio-marduk を補助。

- このチャンネルの目安：絵の切り替え約5回/分＋図解カードは要素を3秒前後ずつ出す。全カットの15%前後をカードにする（001 は 155カット中24枚）
- v5 の目安（2026-11-07 実録事件の競合14本を測定。画面が大きく変わる回数／分。札が出るのも含む）：上位の真紅の事件簿（352万・227万）と日影のこえ・植松回（88万）は 46〜50回/分（1回あたり約1.3秒）。c版は 27.6回/分・2.2秒で、カンテレ・教養TV・キリンと同じ中くらい。遅いのは ずんだ事件記録（5回/分・11秒）
  - 冒頭45秒と3つの山場の前後：約1.3秒ごとに変える（本物の写真の差し替え・寄り・言葉カード）

### §8-1 何を作るか
- 長尺1本につき、1本で成り立つショートを1〜2本（スキル 03 の「単独」）。長尺を切っただけの物・「続きは本編で」で終わる予告は作らない
- 1本の中身は「問い1つ → 記録で分かった事実 → 答え」。長尺の「3つの問い」（§3-2）とは別の、小さい問いを使う。長尺の核（3つの問いの答え・6章の時刻の流れ・終わりの言葉）は明かさない
- 問いの取り方（事実メモにある物だけ）：
  - 数字1つ（例：判決までにかかった年数、公判の回数）
  - 言葉1つ（法廷で争われた語の意味。例：責任能力とは何を指すか）
  - 仕組み1つ（建物・制度・手続きがどうなっているか。まねできる手順には踏みこまない）
  - 報道と記録の違い1つ（長尺のひっくり返しのうち、核ではない物）
- 作らない題材：被害者一人一人の話、事件当日のむごい場面、犯人の言葉だけを切り出して見せる物（ショートは前後の説明が無いので、言い分をそのまま広める形になる）
- 同じ問い・同じ答え・同じ1文目・同じ帯の字を、ほかのショートとも長尺の題とも重ねない

### §8-2 台本の決まり
- 全体 250〜330字、30〜45秒。59.5秒を超えたら出さない。1文は平均20字前後、最長27字。1文に絵1枚
- 最初の1〜2秒は、画面いっぱいの問いか結論。挨拶・名乗り・チャンネル名・「この事件は」の前置きは入れない
- 声は語り（青山龍星 しっとり 84）だけ。聞き手と犯人の声は使わない（30〜45秒に3人の声は入らない）
- 言い方の線は §4 のまま。判決前の人は「容疑者」「被告」と「〜とされる」。断りの言葉は1本に1回まで（短いので、2回入ると話が遠くなる）
- 終わりは答えを言い切って止める。語りで長尺に誘わない・登録を頼まない・「続きが気になる人は」を言わない。長尺へは説明欄の1行目のリンクと固定コメントでつなぐ
- 日付は年月日と曜日で言う。「今日」「昨日」「先日」は使わない
- 禁止表現.txt と check_script.py --short の NG 0件

### §8-3 絵と画面
- 縦 1080×1920。文字は横 192〜888 の中、真ん中そろえ。上 288・下 672・左 48・右 192 には文字を置かない。最初の文字は1行5字・2行まで。帯は大きい字7字・小さい字10字まで
- 絵の決まりは §5 のまま：血・遺体・けが・人に向けた凶器・燃える人を描かない。被害者の顔は写真もAIも使わない。実在の人の顔をAIで似せるのは法廷スケッチだけ。写真とテレビの切り抜きは出どころを sources.md に残す
- 人は §5 の図解（男性＝青・女性＝赤の光）。背景の絵・写真の上に人の線画を載せない
- 画面を3秒以上止めない。動く絵を2つ以上入れる。横の揺れ・横パンは使わない（§5-2）。縦の寄りとゆっくり大きくなる動きは使ってよい
- 隅の表示（§5-4）はショートには出さない（上 288 と右 192 に当たる）
- サムネ用の1コマに「閲覧注意」「狂気」などのあおりを入れない

### §8-4 説明欄とコメント
- 説明欄：1行目に長尺のリンク（長尺が公開されたあとに入れる。公開前はチャンネルのリンク）、「セリフは記録をもとにした再現です」、AI の申告（絵・声）、声のクレジット、出どころ。判決前なら「裁判は続いています」
- 固定コメントで長尺へつなぐのは、長尺が公開されたあと
- 題：問いをそのまま。あおりの語（衝撃・狂気・閲覧注意）は入れない。事実メモに無い事を題にしない

### §8-5 点検（1つでも落ちたら出さない）
1. check_script.py --short NG 0件。禁止表現 0件。字数と秒数を数えて報告する（59.5秒以内）
2. 1本で問いと答えがある。長尺の核を明かしていない。長尺を切っただけになっていない
3. 持ち帰る事実（数字・言葉の意味・仕組み・記録で分かった違い）が1つある。事実メモにある
4. §4 の言い方の線。判決前の人に言い切りが無い
5. 被害者の顔・最期の場面・むごい絵・まねできる手順が無い
6. safezone_check.png で、文字が枠の外に出ていない
7. 全カットの1コマを並べて見て、絵がセリフと合っている・同じ絵が続いていない・文字が切れていない
8. ほかのショート・長尺と、問い・答え・1文目・帯の字・題が重なっていない
9. 説明欄に「セリフは記録をもとにした再現です」と AI の申告がある
10. 声と BGM の音量（−14 LUFS 前後）

### §8-6 出し方
- 枠はまだ入れていない（profile.json の kinds.short.slots と、day_slots.py の shinshiten の on・off は空）。入れるのは、1本目を持ち主が見てOKを出したあと
- 枠の案（仮。持ち主のOKのあとに決める）：長尺の公開の翌日と3日後の 18:00。長尺と同じ日には出さない。枠は固定し、当分動かさない
- 1本目と、型を変えた最初の回は、司令室の確認カードで持ち主のOKを取ってから予約する（§0）。予約の前に、いまある予約を確かめる
- 作るたびに 改善ログ.md に1行（§10）。1度に変えるのは1つ（問いの取り方・1文目の形・帯の字・絵の種類のどれか）
- 数字は §9 と同じに記録する。ショートは 最後まで見た割合・スワイプされずに見られた割合・長尺へ移った数 を足す。10本たまるまでは型を動かさない

## §9 数字の見方
- 公開から72時間と7日の数字を記録（再生・平均視聴率・クリック率・30秒の時点で残る割合・登録）
- 10本たまったら、30秒の割合と平均視聴率の境目を出して学び.md に書く
- 1度に変えるのは1つ（題の言葉・サムネの型・冒頭の場面の選び方・6章の比率のどれか）

## §10 電子ゴミの線と改善ログ
- 出さない4条件（スキル 14）：持ち帰る物が無い／ほかの回と問い・1文目・題が同じ／ショートが長尺を切っただけで、1本としての問いと答えが無い（§8）／絵がセリフと合っていない・同じ絵が続く
- このチャンネルだけの線：あおりだけで中身が報道のまとめと同じ回は出さない。分かれ道と6章の時刻の流れが、その回で初めてつながっていること
- 作るたびに 改善ログ.md に1行。作り始める前に、いちばん下の「次に上げること」を読む
