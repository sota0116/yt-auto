## U0 何を足したか（本編 §0 §1 への足し）
- 中身：犯人が分かっていない事件を、残された物（遺留品・目撃・防犯カメラ・声明や脅迫状）から、犯人の足取りを逆にたどる。「シン視点」は、犯人の側に立つ目線のまま。ただし犯人の心の中は分からないので書かない。書くのは、残された物から警察や報道が組み立てた「犯人がたどったとみられる動き」だけ
- 見る人：報道で事件を知り「なぜまだ捕まらないのか」「何が分かっているのか」が気になったまま終わった人
- 持ち帰る物（電子ゴミの線 1）：毎回、次のどれか1つ以上がある
  - 残された物ごとに、分かったこと・まだ見つかっていないことの一覧
  - 説ごとに、支える事実と合わない事実の対比
  - 時刻ごとの動きの中で、誰も説明できていない空白の時間
- 本数：型A と 型B を、おおむね 1：1。前の回と違う型を先にする（リサーチ係の 1pick が見る）

## U1 題材の選び方（本編 §2 への足し）
- 選ぶ物：ネタ帳の kind「未解決」。nazo（動画の芯にする謎）が1文で言える物を先にする
- 節目：発生から○年（10・20・25・30年）、懸賞金の延長、時効の撤廃・成立から○年、新しい報道（DNA・新証言）。近い物を先にする
- 扱わない物
  - 疑われた個人の実名を出さないと話が成り立たない事件
  - 冤罪の疑いを含めて、特定の人が今も犯人扱いされている事件
  - 発生から5年たっていない事件（捜査の妨げ・関係者が特定されやすい）
  - 被害者が今も生きていて、本人が特定される事件
- 時効前の事件は、書く直前に警察の公式ページで、捜査本部の名前・電話番号・懸賞金の額と期限を確かめる。URL と確かめた日を事実メモの頭に書く

## U2 章の順（置き換え：本編 §3 の章の表）
型B は次の順で固定。章の中身と山場だけを毎回変える。

| 章 | 中身 | 目安の比率 |
|---|---|---|
| 冒頭（約45秒） | 残された物から入る。①警察が公開した遺留品・似顔絵・防犯カメラの1枚 ②発生から今日までの年数 ③「なぜまだ見つかっていないのか」の問い。この順で出して、題名カード → 1章へ。犯人の言葉が記録に残る事件（声明・脅迫状）だけは、本編どおり黒地の言葉カードを①にしてよい。挨拶・名乗り・「この動画では」は入れない | 5% |
| 1 その日までの場所 | 現場と時代：建物・街・その日の天気や行事。被害者は「誰が・どんな暮らし」を1〜2文だけ | 10% |
| 2 その日の時刻 | 分かっている動きを時刻順に、分単位で。最後に目撃された時刻・発見の時刻。誰も説明できていない空白の時間をはっきり示す | 18% |
| 3 発見と最初の捜査 | 通報・現場検証・最初の判断。あとで問題にされた点（初動の遅れ・現場の扱いなど）は、報道や検証で指摘された範囲だけ | 12% |
| 4 残された物 | **いちばん長い章**。遺留品・DNA・指紋・目撃・声明を1つずつ。物ごとに「そこから分かったこと」と「まだ見つかっていないこと」。ひっくり返し（思われていたこと → 鑑定や捜査で分かった違う事実）をここに集める | 20% |
| 5 犯人像と説 | 警察が公開した犯人像（年齢・身長・持ち物など）→ 報道・専門家・本で唱えられた説を2〜4つ。説ごとに「支える事実」と「合わない事実」を並べる。どれか1つに決めない | 15% |
| 6 捜査の今 | 時効（撤廃か成立か）、懸賞金、延べの捜査員数、最近の動き（新しい鑑定・新しい証言）、遺族の呼びかけ（報道に出た言葉を文字で短く） | 10% |
| 7 終わり | 3つの問いのうち、答えが出た物と出ていない物を分ける → 答えの出ない問いを1つ（冒頭の残された物に戻す）→ 時効前の事件は情報提供先を画面の文字で出す（警察の窓口と電話番号。語りでは「情報は○○警察署へ」と1文だけ）→ 現場の今か慰霊の場所の写真 → 無音で終える。まとめの説明・次回予告・登録のお願いはしない | 10% |

- 山場は3つ（本編 §3 と同じ数）：約30%（空白の時間が見える所）／約55%（いちばん大きな遺留品のひっくり返し）／約80%（説が2つにぶつかる所。合わない事実を出す）。山場の前後で絵の切り替えを速くする（本編 §5-2）
- "peak": true は4章に置く（本編は6章。型B は4章がいちばん長いため）
- 聞き手（kikite）：本編と同じ形（疑い → 記録で答える → 受け）。章に2〜3回、4章は1〜2回。型B では「じゃあ犯人は○○なんじゃ？」と決めつけを口にさせて、語りが合わない事実で返す形を1本に2回まで使ってよい（見ている人が思いつく説を先に言わせて、事実で確かめる）
- 犯人の声（hannin）：記録に残る犯人の言葉（声明・脅迫状・電話の録音の文字起こし）がある事件だけ使う。1本で0〜4カット。無い事件では使わない。犯人のセリフを作らない（再現のセリフも無し）
- 分かれ道の演出（「この決断が○○の人生を大きく分ける」）は型B では使わない。犯人の決断は分からないため
- 長さ・場所の言葉・伏線・登録の呼びかけ無し・引っ張り禁止は本編のまま

## U3 問いとひっくり返し（本編 §3-2 への足し）
- 3つの問いの例：「犯人はどこから入り、どこへ消えたのか」「残された○○は何を語っているのか」「なぜ○年たっても見つからないのか」。冒頭で約束し、7章で「答えが出た所」と「まだ見つかっていない所」に分けて閉じる
- 型B では、答えが出ない問いが残ってよい。ただし「分かっていない」の一言で閉じず、何が見つかっていないかを具体に言う（例「同じトレーナーは130着売られ、買った人が分かったのは12着」。数字は事実メモにある物だけ）
- ひっくり返しの元は、鑑定・捜査の公表・判決（関連事件）・大手の報道だけ。説を事実のように見せてひっくり返さない

## U4 事実と推測の分け方（本編 §4 への足し。本編の言い方の線はそのまま）
- 犯人を決めつけない。「犯人は〜だ」「〜の仕業」「真相は」「真犯人」は使わない
- 犯人について言える物は3種類だけ
  - 残された物そのもの → 言い切ってよい（例 現場に指紋が残っていた）
  - 警察の見立て・公開した犯人像 → 「警察は〜とみている」
  - 報道・専門家・本の説 → 出どころを主語にして言う（例「元捜査幹部は〜とみる」）。文末の「とされる」で包まない（本編 §4 の断りの量の目安 1000字あたり1回以下は型B も同じ）
- 疑われた人・取り調べを受けた人・報道で名前や写真が出た人の、実名・顔・住んでいた場所・特定できる話は出さない。亡くなった人も同じ。「ある男性」「当時○代の男性」まで
- ネットの噂・掲示板の「真相」・まとめサイトは使わない（本編どおり）。有名な噂でも、大手の報道か本で確かめられない物は説に入れない
- 説は2〜4つ。どの説にも「合わない事実」を最低1つ並べる。「最も有力」と言ってよいのは、警察か複数の大手報道がそう書いている時だけ
- 「分かっていない」は禁止表現（2026-11-12 追加の伝聞・メタの言い方）に入っているので、型B でもそのまま避ける。代わりに「指紋の持ち主は今も特定されていない」「凶器は見つかっていない」のように、何が見つかっていないかを言う
- 被害者：名前は報道で広く出た範囲まで。暮らしは1〜2文。最期・遺体・家族の悲しみの描写は足さない（本編 §6 の5）。遺体の状態は書かない。どうしても謎の芯になる時（バラバラ事件など）は「同じ大きさに切られていた」程度にとどめ、道具と切り方は書かない
- まねできる手順を書かない：侵入の仕方・発火装置の作り・痕跡の消し方・逃げ方は、「何をしたか」の名前まで。手順・量・道具の使い方は書かない
- 時効前の事件は、概要欄の頭の近くに情報提供先（警察署・電話番号・公式ページのURL・懸賞金の額と期限・確かめた日）を書く

## U5 絵とサムネ（本編 §5 への足し）
- 犯人の顔は誰にも分からないので、AI で犯人の顔を作らない。犯人は影・後ろ姿・顔の無い人形で描く（本編の image_rules の without_chars と同じ）
- 警察が公開した似顔絵・防犯カメラの画像・遺留品の写真は、出どころつきで使ってよい（公式ページのURLを記録）
- 疑われた人の顔写真は使わない（U4）
- 4章の遺留品は、1つにつき1枚の札（物の名前・分かったこと・まだ見つかっていないこと）にする。本編 §5-3 のボード型で、遺留品を並べた「証拠のボード」を章の頭と終わりに出す
- 2章の時刻は時刻表の図にする。空白の時間は色を変えて見せる
- サムネ：犯人の顔は無し。遺留品か現場の今の写真＋年数（例「26年」）＋短い問い。「犯人判明」「真犯人」「閲覧注意」などのあおりは入れない。直近のサムネと同じ写真・同じ素材を使わない（本編 §6 の9）
- 題：問いの形を基本にする（例「なぜ○○年たっても捕まらないのか」）。説の1つを犯人と決めた題にしない

## U6 点検（本編 §6 に足す。型B の回は本編の 1〜22 と、下の U-1〜U-9 を全部見る）
- U-1 犯人の決めつけが無い（「犯人は〜だ」「〜の仕業」「真相は」「真犯人」が 0件）
- U-2 疑われた人・報道で名前が出た人の、実名・顔・特定できる話が 0件
- U-3 説が2〜4つ、どの説にも合わない事実が1つ以上ある。出どころが主語で言えている
- U-4 犯人の顔の AI 絵が 0枚。犯人のセリフ（記録に無い物）が 0件
- U-5 遺体の状態・最期の場面・手順（侵入・発火・痕跡を消す）が無い
- U-6 時効前の事件：情報提供先が7章の画面と概要欄にあり、番号と懸賞金を書く直前に公式ページで確かめた（URL と日付を事実メモの頭に書いた）
- U-7 3つの問いを7章で「答えが出た物」と「まだ見つかっていない物」に分けて閉じている。「分かっていない」の一言で閉じていない
- U-8 本編 §6 の3（冒頭）は、型B では「最初の3秒に挨拶・名乗りが無い／45秒までに 残された物の1枚・年数・『なぜ』の問い がある」で判定する
- U-9 本編 §6 の13（法廷画）は、関連の裁判が無い型B の回では見ない
- U-10 考察の受け口（U9）：概要欄の末と投稿案の「## 最初のコメント（固定用）」に、5章の説の番号つき一覧と問いが1つある。最初のコメントに名前の書き込みを消す1文がある。語りに「コメントで」の呼びかけが無い。説の一覧はどれも推していない

## U7 作業の順（本編 §7 への足し）
- 本編 §7 の順のまま。ただし「事実メモ → 1本の主張と3つの問い」の間に、「残された物の一覧（物・分かったこと・まだ見つかっていないこと・出どころ）」と「説の対比表（説・支える事実・合わない事実・出どころ）」を事実メモの下に書く
- 型B の企画書は 企画書_型_v2.md の「型B」を使う

## U9 見た人の考察の受け口（v2 で足した）
- 語り（7章）は変えない。無音で終え、「コメントで教えて」も登録のお願いも言わない（語りで頼むと、答えの出ない問いの余韻が切れる。本編の終わり方と同じ）
- 考察の受け口は2か所。どちらも投稿案に書く
  - 概要欄の末（情報提供先・目次より下）：5章の説を番号つきで1行ずつ（説の短い名前と、唱えた出どころ）＋問いを1つ。例「どの説がいちばん残された物と合うと思いますか。合わない事実をどう読むかも、番号と一緒に聞かせてください。」
  - 最初のコメント：同じ説の一覧と問い。最後の行に必ず「実在の方のお名前や、特定できる書き込みは消します。」。投稿案に「## 最初のコメント（固定用）」の見出しとコードブロックで書く（固定は API でできないので、持ち主が公開後に入れて固定する）
- 説の一覧に入れてよいのは、企画書の説の対比表にある物だけ。どれかを推す言い方・「最も有力」の印は付けない
- 問いは説の当てっこにしない。「犯人は誰だと思いますか」は使わない（名前の書き込みを呼ぶ）。聞くのは「どの説が合うか」「どの残された物がいちばん気になったか」まで
- 名前の書き込みは持ち主が見て消す（自動では消さない）。2本続けて名前の書き込みが目立った時は、問いを「どの残された物がいちばん気になりましたか」だけに替える（改善ログに1行）

## U8 ショート（本編 §8 への足し）
