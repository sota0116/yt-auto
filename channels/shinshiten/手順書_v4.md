形は nihongi の手順書（§0〜§10）にそろえる。変えるのは、週報の改善案を持ち主が「採用」した時だけ（スキル 10・14）。学び.md とぶつかったら、この手順書が勝つ。

## §0 名前と出し方
- チャンネル名：シン視点事件簿
- 中身：実際の事件を、犯人（判決前なら容疑者・被告）の側から順にたどる。悪者として片づけずに、どこで分かれ道があったかを見る
- 出す物：長尺だけ。週1〜2本（仮の枠は 水・日 の 21:00。競合の公開時刻をまとめたら決め直し、決めたら当分動かさない）
- 作り方：フルAI（台本 Claude、声 VOICEVOX、絵 AI＋報道写真）。投稿は自動予約。ただし1本目と、型を変えた最初の回は持ち主のOKのあとに出す
- 英語版は作らない

## §1 誰に向けるか
- 事件のニュースを見て「なぜそうなったのか」が気になったまま終わった人。ワイドショーの怒りや断罪ではなく、筋道を知りたい人
- 見る理由：その人がどんな道をたどって事件の日に至ったかを、記録に基づいて順に知れる。報道では切れ切れだった話が1本でつながる
- 持ち帰る物（電子ゴミの線 1）：分かれ道になった出来事と時刻、法廷で何が争われたか、専門家がどう見たか、のどれかが毎回ある

## §2 企画（題材の選び方）
- 決め方は「伸びるかどうか」だけ（2026-11-06 本人）。有名な事件・最近の事件・最近思い出された事件（判決・逮捕・再審・節目の年）
- ネタ帳.json の rows を上から。節目（判決の日・逮捕の報道・事件から○年）が近い物を先にする
- 公判中・起訴前の題材は、書く直前に今どこまで決まっているかを報道で確かめ、ネタ帳の note に日付つきで書く
- 同じ犯人を2回扱わない（続編は、新しい判決・再審が出た時だけ）

## §3 型（長尺の台本）
章の順番は固定。章の中身と山場だけを毎回変える。

| 章 | 中身 | 目安の比率 |
|---|---|---|
| 冒頭 | 1秒目に検索される言葉＋この動画で分かること（例 001 A01「京アニ放火事件。青葉真司は、なぜ京アニを狙ったのか。」）→ 何をたどるか（生い立ち→当日の30分→法廷）→ 事件当日の1場面（時刻つき）→ 1章（半生）へ。事件の話は冒頭だけにして、すぐ半生に入る | 5% |
| 1 生い立ち | 家族・育った土地・学校。記録に残る出来事だけ | 12% |
| 2 つまずき | 仕事・人間関係・お金。最初の分かれ道 | 12% |
| 3 心の動き | 本人の供述・書き残した物・精神鑑定で分かったこと。犯罪心理学の見方 | 12% |
| 4 その後の環境 | 孤立・転居・最後の分かれ道。「この決断が○○の人生を大きく分けることに」 | 10% |
| 5 準備 | 下見・持ち物をそろえた日付・前日の動き | 10% |
| 6 事件当日の手口 | **いちばん長い章**。時刻ごとの動き（分単位）、建物の作り、法廷の供述、止められた瞬間・捕まった瞬間 | 22% |
| 7 法廷と世の中 | 判決・争点・専門家・メディア・世論の見方。未解明の点 | 10% |
| 8 IF と終わり | 分かれ道のどこで違う選択があり得たか（IF）。言い切らず、記録に戻って終える | 7% |

- 6章に入れる物：下見の日と回数、準備の物と買った日（品名まで。量・配合・作り方は書かない）、時刻ごとの動き、建物の間取り・出入り口・逃げ道（報道と判決で出た範囲）、本人の供述、周りの人の動き、止められた・捕まった時の様子
- 6章に入れない物：まねできる手順（量・配合・着火や凶器の使い方・見つからない方法）、むごい絵、被害者一人一人の最期
- 分かれ道の演出：「この決断が、○○の人生を大きく分けることになる」を2〜3回まで。乱発しない
- IF は8章だけ。「もしこの時〜だったら」は1〜2個。記録にある別の選択肢から作る（作り話の人生を足さない）
- 聞き手（kikite）は章ごとに1〜3回。視聴者が思う疑問を先に口にする役。ツッコミは事実を確かめる問いにする（茶化さない）
- 犯人の声（hannin）は、供述・手紙・書き込みなど記録に残る言葉だけ。言い回しは要約してよいが、中身は足さない
- 記録の声（kiroku）は、日付・時刻・判決文・数字を読む時だけ
- スキルの決まりはそのまま：check_script NG 0件、"anim":"kling"（か card）を章の数＋1以上、"peak": true を1つ（6章に置く）、伏線は40%より前・回収は後ろ、登録の呼びかけは1回で30〜70%の位置、引っ張り禁止、冒頭に挨拶・名乗り禁止
- 長さは目的にしない。中身が尽きたら終える（8分未満でも、門を通れば出す）

## §4 事実と推測の分け方
- 使う元：判決文・裁判の報道（大手紙・NHK・通信社）・本人の手記や公開された文書・公的な報告書。まとめサイト・掲示板の噂は使わない
- 書く前に事実メモを作る（例 crime/facts_kyoani.md）。1行に1つ、元の記事を添える。台本の事実はメモにある物だけ
- 言い方の線：
  - 判決で認められた事実 → 言い切ってよい
  - 本人の供述 → 「〜と供述した」「〜と話している」
  - 検察・弁護側の主張 → 「検察は〜と主張」
  - 専門家の見方 → 名前か肩書き＋「〜とみる」
  - 分からない事 → 「分かっていない」と言う。埋めない
- 判決前の人：「容疑者」「被告」を付け、事実は「〜とされる」。有罪と決めつけない。概要欄にも「裁判は続いています」と書く
- 「真実は」「本当の動機は」と言い切らない（禁止表現.txt）
- 概要欄に「セリフは記録をもとにした再現です」を入れる（本編の画面・語りには出さない。v4〜 持ち主の指摘：メタ的なことは言わない）

### §5-2 見せ方の型（視点系の競合から。2026-11-06 測定）
参考：夜ふかし考察部（@yofukashi-kousatsu・中央値 7.9万再生）を主、裏視点（@ura-shiten）・studio-marduk を補助。
- 速さ：夜ふかしは場面の切り替えが約4.8回/分。ただし1枚の中で要素が順に出るので、画面は約3秒ごとに変わる。marduk は 18.8回/分（速さの参考だけ）
- このチャンネルの目安：絵の切り替え約5回/分＋図解カードは要素を3秒前後ずつ出す。全カットの15%前後をカードにする（001 は 155カット中24枚）

| 競合の要素 | このチャンネルでの作り方（shinshiten_cards.py の type） | 使う場面 |
|---|---|---|
| 紺の「捜査室」の板／暗くぼかした絵の背景 | カードの背景（既定の紺） | カード全部 |
| 左上の大きな細字の日付・時刻（例 12.31） | date | 章の頭・日付が変わる所・6章の時刻 |
| 白い小札（黒字）・赤い札 | tag | 場所・人数・持ち物など一言の事実 |
| 赤く光る強調語 | big | 数字・決定的な一言（1枚に1つ） |
| 赤い判の CASE FILE の紙 | paper＋stamp | 人物の基本情報（1章の頭）・判決 |
| 傾いた写真の額＋左上の出どころ札 | frame | 報道写真・指名手配写真（sources.md に URL） |
| 赤い線でつないだ丸い顔アイコン | mark＋link | 人のつながり（顔は描かない。名札で） |
| 年表・時刻の流れ | tl_line＋tl_node／帯（strip） | 4章〜6章の流れ・数日の動き |
| 地図の赤い点＋大きな数字 | mark＋link | 移動。距離は報道に出た数字だけ |
| 間取り・建物の断面 | section・sec_atrium・sec_sprink・sec_door・sec_smoke | 6章の建物の作り |
| 箱と矢印の流れ（2列の比べも） | box＋link＋bracket | 争点・分かれ道・判決の理由 |

- カードの決まり
  - 字幕が下に出るので、要素は y 820 より上に置く
  - 章の頭のカットは、章タイトルが 0.1〜2.9秒に重なるので、カードの "start": 3.0 で中身を遅らせる
  - 画面に「模式図」「位置は模式図」「とされる」などの注記（note）を出さない。断りは概要欄に1回だけ書く（「位置関係の図は模式図です」）。距離・広さは事実メモにある数字だけ。駅名など事実メモに無い地名を足さない
  - 文字は PIL で描く（ffmpeg の drawtext は落ちる）
  - 1枚に要素は5〜8個まで。出す時刻は語りの言葉に合わせる（"at": "k:言葉"）
  - カードにしたカットは script.json から label・same_as・big・anim を外す（字幕と札が二重になるため）
- 動く絵：shinshiten_motion_v1_20261106.py（2026-11-06〜。still_motion.py の後継）。カードは要素ごとに出し（frame→drop／tag→slide・pop／赤い big→stamp＋揺れと赤い光）、最初の要素へ寄ってから引く。実写と素のカットは揺れ・粒子・周辺減光・ちらつき。切り替え（whip・push・smoke）は章の境目と山場だけ。注記・章札・クレジットは画面に出さない。Lovart の動画はクレジットを使うので使わない。Kling は持ち主の許可がある時だけ（Kling で作ったカットは触らない）

## §6 点検（品質の門。1つでも落ちたら出さない）
1. check_script.py NG 0件
2. 禁止表現.txt に当たる語が 0件
3. 冒頭：最初の3秒に挨拶・名乗りが無い／1秒目の画面と語りに事件名・人名と「なぜ〜か」（分かること）がある／promise がある

6. まねできる手順が無い（量・配合・道具の使い方・見つからない方法）
7. 声と BGM の音量（−14 LUFS 前後・差は約25dB）
8. 全カットを並べて見て、むごい絵・文字切れ・同じ絵の連続が無い
9. サムネとタイトルの点検 NG 0件。サムネに「閲覧注意」「狂気」などのあおりを入れない
10. 概要欄に「セリフは記録をもとにした再現です」・再現イメージと模式図の断り・出どころ・写真の作者とライセンス・（判決前なら）「裁判は続いています」がある
