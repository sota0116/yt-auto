## §0 名前と出し方
- チャンネル名：シン視点事件簿
- 中身：実際の事件を、犯人（判決前なら容疑者・被告）の側から順にたどる。悪者として片づけずに、どこで分かれ道があったかを見る
- 出す物：長尺だけ。週1〜2本（仮の枠は 水・日 の 21:00。競合の公開時刻をまとめたら決め直し、決めたら当分動かさない）
- 作り方：フルAI（台本 Claude、声 VOICEVOX、絵 AI＋報道写真）。投稿は自動予約。ただし1本目と、型を変えた最初の回は持ち主のOKのあとに出す
- 英語版は作らない

## §1 誰に向けるか
- 事件のニュースを見て「なぜそうなったのか」が気になったまま終わった人。ワイドショーの怒りや断罪ではなく、筋道を知りたい人
- 見る理由：その人がどんな道をたどって事件の日に至ったかを、記録に基づいて順に知れる。報道では切れ切れだった話が1本でつながる
- 持ち帰る物（電子ゴミの線 1）：分かれ道になった出来事と時刻、法廷で何が争われたか、専門家がどう見たか、のどれかが毎回ある

## §2 企画（題材の選び方）
- 決め方は「伸びるかどうか」だけ（2026-11-06 本人）。有名な事件・最近の事件・最近思い出された事件（判決・逮捕・再審・節目の年）
- ネタ帳.json の rows を上から。節目（判決の日・逮捕の報道・事件から○年）が近い物を先にする
- 公判中・起訴前の題材は、書く直前に今どこまで決まっているかを報道で確かめ、ネタ帳の note に日付つきで書く
- 同じ犯人を2回扱わない（続編は、新しい判決・再審が出た時だけ）

## §3 型（長尺の台本）
章の順番は固定。章の中身と山場だけを毎回変える。

| 章 | 中身 | 目安の比率 |
|---|---|---|
| 冒頭（約45秒） | 衝撃から入る：黒地に犯人の法廷の言葉1行（赤字の語あり）→ 事件当日の本物の写真（燃える建物など）→ 被害の数字（例 死者36・負傷32）→ 問い「なぜ」→ 題名カード → 1章へ。挨拶・名乗り・「この動画では」の説明はしない | 5% |
| 1 生い立ち | 家族・育った土地・学校。記録に残る出来事だけ | 12% |
| 2 つまずき | 仕事・人間関係・お金。最初の分かれ道 | 12% |
| 3 心の動き | 本人の供述・書き残した物・精神鑑定で分かったこと。犯罪心理学の見方 | 12% |
| 4 その後の環境 | 孤立・転居・最後の分かれ道。「この決断が○○の人生を大きく分けることに」 | 10% |
| 5 準備 | 下見・持ち物をそろえた日付・前日の動き | 10% |
| 6 事件当日の手口 | **いちばん長い章**。時刻ごとの動き（分単位）、建物の作り、法廷の供述、止められた瞬間・捕まった瞬間 | 22% |
| 7 法廷と世の中 | 判決・争点・専門家・メディア・世論の見方。未解明の点 | 10% |
| 8 終わり | IF は入れない（v5〜）。法廷か治療の場で本人が口にした言葉 → 答えの出ない問いを1つ → 慰霊の場所（銘板・献花）の写真に追悼の一行 → 無音で終える。まとめの説明・次回予告・登録のお願いはしない | 7% |

- 6章に入れる物：下見の日と回数、準備の物と買った日（品名まで。量・配合・作り方は書かない）、時刻ごとの動き、建物の間取り・出入り口・逃げ道（報道と判決で出た範囲）、本人の供述、周りの人の動き、止められた・捕まった時の様子
- 6章に入れない物：まねできる手順（量・配合・着火や凶器の使い方・見つからない方法）、むごい絵、被害者一人一人の最期
- 分かれ道の演出：「この決断が、○○の人生を大きく分けることになる」を2〜3回まで。乱発しない
- 山場は3つ置く（v5〜）：約30%（最初の分かれ道や思い込みが固まる所。黒地の言葉カード）／約65%（事件直前のためらいの時間。犯人の短い独白）／約85%（法廷。法廷画＋最終陳述＋遺族の言葉は文字で）。山場の前後で絵の切り替えを速くする（§5-2）
- IF（「もしこの時〜だったら」）は入れない（v5〜。競合14本のどこにも無い）
- 聞き手（kikite）は短い問いだけ。1回1文・章に1〜2回。視聴者が思う疑問を先に口にする役。茶化さない。立ち絵キャラは画面に出さない（競合14本で掛け合いキャラは1本だけ）
- 犯人の言葉は、基本は黒地の言葉カード（白字。脅し・決定的な語だけ赤）。声（hannin）で読むのは山場など数か所だけ（1本で3〜6カット）。供述・手紙・書き込みなど記録に残る言葉だけで、言い回しは要約してよいが中身は足さない
- 記録の声（kiroku）は v5 では語りと同じ声で読む（2026-11-07 持ち主が選んだのは語り・聞き手・犯人の3つ。kiroku の声は選ばれていないので、語りの声にまとめた。仮の決め）
- スキルの決まりはそのまま：check_script NG 0件、"anim":"kling"（か card）を章の数＋1以上、"peak": true を1つ（6章に置く）、伏線は40%より前・回収は後ろ、登録の呼びかけは入れない（v5〜。スキルの既定より持ち主の指示が優先）、「続きが気になる人は」などの引っ張りも禁止、冒頭に挨拶・名乗り禁止
- 長さは目的にしない。中身が尽きたら終える（8分未満でも、門を通れば出す）
- 場所の言葉は、見ている人が絵を見ずに分かる語にする（v6〜）。「玄関」「現場」「そこ」のように、どの建物のどこか分からない語は使わない。「スタジオの正面の入り口」「1階の受付の前」のように、建物の名前と場所を言う。2回目からは「入り口」でよい（001 v6 で「玄関に向かったのか」が意味不明と言われた）

## §4 事実と推測の分け方
- 使う元：判決文・裁判の報道（大手紙・NHK・通信社）・本人の手記や公開された文書・公的な報告書。まとめサイト・掲示板の噂は使わない
- 書く前に事実メモを作る（例 crime/facts_kyoani.md）。1行に1つ、元の記事を添える。台本の事実はメモにある物だけ
- 言い方の線：
  - 判決で認められた事実 → 言い切ってよい
  - 本人の供述 → 「〜と供述した」「〜と話している」
  - 検察・弁護側の主張 → 「検察は〜と主張」
  - 専門家の見方 → 名前か肩書き＋「〜とみる」
  - 分からない事 → 「分かっていない」と言う。埋めない
- 判決前の人：「容疑者」「被告」を付け、事実は「〜とされる」。有罪と決めつけない。概要欄にも「裁判は続いています」と書く
- 「真実は」「本当の動機は」と言い切らない（禁止表現.txt）
- 概要欄に「セリフは記録をもとにした再現です」を入れる（本編の画面・語りには出さない。v4〜 持ち主の指摘：メタ的なことは言わない）

- テレビの映像：動画のまま流さない。1コマを切り抜いた静止画として、写真と同じ扱いで使う（局名の小札・sources.md に URL と時刻）。1枚の表示は数秒まで（自動照合で収益が止まる・削除される危険を下げるため）
- 法廷画（v6〜 裁判がある回は必須）：7章の法廷の場面（初公判・被告人質問・精神鑑定の争点・判決・最終陳述）には必ず法廷画を出す。1本に3枚以上が目安（001 は6枚）

  - 無い場面は AI で法廷スケッチを作る（被告の姿を含む。鉛筆と淡い色の素描、法廷の位置関係は報道の範囲）
  - 絵に局のロゴ・字幕・見出しの文字が入っていたら、切り抜いて外す（`_sozai/court/crop/`）
  - 作業フォルダの `court_src.json` に {"CS01": {"kind": "real", "credit": "関西テレビ"}} の形で、本物か AI かと出どころを書く。額の札は「法廷画（関西テレビ）」または「法廷画（記録をもとにした再現イラスト）」になる
  - 概要欄：本物は「※法廷画（報道より引用）」の節に局名と記事 URL、「法廷画は一部を切り抜いています」。AI は「法廷の絵は記録をもとにした再現イラスト」
  - 報道の法廷画は引用の形で使う。公開してよいかは持ち主が決める（Claude は投稿しない）
- 人物の図解（v6〜）：人はピクトグラム型の図（丸い頭と体の形）で描き、ネオンの光で男女を分ける。**男性＝青、女性＝赤**。子ども（age: child）は小さく、医師は白衣、弁護士・検察・学者はスーツ（outfit）。名札は図の下に付ける。顔のない線画の人影（v6 までの sil）は使わない
  - カードの sil 要素に "gender": "male"|"female"・"age": "adult"|"child"・"outfit" を必ず書く
  - 名札と字幕を重ねない（名札は y 820 より上）
- 背景の絵と重ねる物の決まり（v6〜）
  - 背景に絵・写真があるボードは、背景をぼかさずに見せる（board3）。その上に人物の線画・図解を載せない（001 v6 で「背景画像に線画が入って見れない」）。人を見せたい時は、背景を無地にして図解だけにするか、写真の額だけにする
  - 背景の絵にすでに文字（時刻・数字・「十数分」など）があるカードには、同じ文字の札・アイコンを重ねない。足すなら絵の文字がない所へ
- 火災の回（v6〜）：火が出る・火を放つ・燃え広がる場面の図解には火を描く（カードの fire 要素）
  - kind "ambient"：画面のふちが赤く揺れて火の粉が舞う（火が出た時刻から）
  - kind "flame"：建物の断面・間取りの中で、燃えている場所に炎を立てる（x0〜x1・y・h、layer は絵の下 under か上 over）。燃え広がる時は 2つ目の flame を "at" を遅らせて大きく出す
  - 燃える人・やけどの描写はしない（§5 の絵の決まりのまま）
- 主役は本物の写真（事件の場所・当日・逮捕時・裁判所・慰霊の場所）。AI の絵は場面のつなぎだけにする。文字の図解カードは人物カードと年表の札くらいまで減らす
- 地図・時刻表・間取りは card（動く図）で作る。6章の時刻ごとの動きは、時計と地図のカードを中心にする
- 1本ごとに、全カットの1コマを1枚に並べて Claude が見る（文字切れ・同じ絵の連続・むごい絵が混ざっていないか）

### §5-2 見せ方の型（視点系の競合から。2026-11-06 測定）
参考：夜ふかし考察部（@yofukashi-kousatsu・中央値 7.9万再生）を主、裏視点（@ura-shiten）・studio-marduk を補助。
- 速さ：夜ふかしは場面の切り替えが約4.8回/分。ただし1枚の中で要素が順に出るので、画面は約3秒ごとに変わる。marduk は 18.8回/分（速さの参考だけ）
- このチャンネルの目安：絵の切り替え約5回/分＋図解カードは要素を3秒前後ずつ出す。全カットの15%前後をカードにする（001 は 155カット中24枚）
- v5 の目安（2026-11-07 実録事件の競合14本を測定。画面が大きく変わる回数／分。札が出るのも含む）：上位の真紅の事件簿（352万・227万）と日影のこえ・植松回（88万）は 46〜50回/分（1回あたり約1.3秒）。c版は 27.6回/分・2.2秒で、カンテレ・教養TV・キリンと同じ中くらい。遅いのは ずんだ事件記録（5回/分・11秒）
  - 冒頭45秒と3つの山場の前後：約1.3秒ごとに変える（本物の写真の差し替え・寄り・言葉カード）
  - それ以外：約2秒ごと。間を見せる所だけ5秒以上
  - 動きの種類を混ぜる：写真の寄り・横移動・一瞬の白い光（シャッター）・言葉カードの叩きつけ・黒の一拍。同じ寄りだけを続けない
- 中身が動く素材（v5〜。2026-11-07 測定：画面の中身が動いている時間の割合。止まった絵の寄り・横移動は数えない）
  - 測り方：scratchpad/tools/inner_motion.py（20秒×12か所・オプティカルフローで「画面全体の寄り・横移動」で説明できない動きを数える）。字幕や札の出入りも混ざるので、見本のコマを目で見て確かめる
  - 結果：真紅 97%（人・手・警官などの汎用の実写動画素材を白黒にして字幕を乗せる。事件そのものの映像ではない）／日影 植松 63%（実際の場所の動画をゆっくり進む撮り方）／カンテレ 52%（印刷した写真や法廷画を机に並べ、カメラが奥行きのある所を動く）／キリン すすきの 51%（絵の中の部品が動く）／Algometry 33%（人間の実写＋手元の実写素材）
  - c版：22%と出たが、見本8か所はすべて札や字幕の出入りで、絵の中身は動いていなかった。実際はほぼ0%（推測）。写真に見立てたAIの絵を差し替えて寄るだけだったので、紙芝居に見えた
  - 目安：中身が動く時間を全体の約半分にする。作り方は ①白黒にそろえた汎用の実写動画素材（Pexels・Pixabay の動画。人の手・歩く足・雨・炎・パトカーの灯・廊下など。「イメージ」と札を付け、事件そのものの映像のふりはしない）②本物の写真や法廷画を「机の上の紙」として奥行きのある所で撮る見せ方（カンテレ型）③場所の写真を手前と奥に分けて動かす立体の寄り ④AIの絵から作る動画（"anim":"kling"）を山場に
  - 動かさないもの：黒地の言葉カード（犯人の言葉）と、間を置く所。ここは止めることで効かせる

- カードの決まり
  - 字幕が下に出るので、要素は y 820 より上に置く
  - 章の頭のカットは、章タイトルが 0.1〜2.9秒に重なるので、カードの "start": 3.0 で中身を遅らせる
  - 画面に「模式図」「位置は模式図」「とされる」などの注記（note）を出さない。断りは概要欄に1回だけ書く（「位置関係の図は模式図です」）。距離・広さは事実メモにある数字だけ。駅名など事実メモに無い地名を足さない
  - 文字は PIL で描く（ffmpeg の drawtext は落ちる）
  - 1枚に要素は5〜8個まで。出す時刻は語りの言葉に合わせる（"at": "k:言葉"）
