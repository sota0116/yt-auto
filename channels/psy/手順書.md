## §2 1本の形

- 長さ：語りの字数 4,900〜6,000字（句読点・かっこを除いて数える）。組み立てで声を1.28倍にするので、約16〜19分になる（001 は句読点を除いて 5,254字・17分1秒・309字/分）。
- カット：1カット1〜2文、20〜45字。全部で170〜220カット。
- カットの id：章ごとに英大文字1字（つかみ A、第1章 B、第2章 C …）＋2けたの番号（A01・B01）。あとから足したカットは B04b のように小文字をつける。
- 章：つかみ（A）のあとに、前提の章1つ＋特徴の章4〜6つ＋暮らしの工夫の章1つ＋まとめ（合わせて7〜9章）。章の頭のカットに "chapter": "章の名前（20字以内）" を書く。特徴の章の名前は「特徴1　〇〇」の形でよい。最後の章は「まとめ」。

## §3 組み立て（競合の伸びた回の型。2026-10-29 から）

1. つかみ（A・語りの最初の60〜90秒。300〜450字・10〜16カット）
   - 見る人の毎日の1場面を、時刻・物・体の感じで具体的に2〜4カット（例「夜中の3時。ふと目が覚めて時計を見ると、また同じ時刻。」）。
   - 問いを1回：「そんな経験は、ありませんか？」（言い方は回ごとに少し変えてよい。「ありませんか」は入れる）。
   - 世間でよく言われる思い込みを1〜2文（「年のせいかな、と思いがちです」）。
   - ひっくり返す1文（例「ところが、心理学の研究をたどると、まったく別のことが見えてきます。」。毎回同じ文にしない）。
   - 意外な予告を1〜2文。答えの一部を先に見せて、中身で引く（例「その人の頭の中では、眠っている間に、ある片づけが行われていました。」）。
   - 予告の文1つ：「今回は、〇〇な人に共通する、N個の特徴を、心理学の研究からお話しします。」（N は4〜6。「特徴」は「サイン」「共通点」「理由」でもよい。「と、暮らしで試せる3つの工夫」を足してよい）。
2. 前提の章（第1章）：毎日の場面から入る（つかみの場面の続きや、その場面の人の一日）。そのあと、その場面がどれくらい多いかを数字1つ（多くて2つ）で（例「〇〇の調べでは、3人に1人が〜」。facts.json の数字だけ）と、心や脳の仕組みのごく短い説明。研究者の名前・人数・方法・年代別の結果を並べない（並べると講義になり、台本ゲートで5点以下になる。005 で2回あった）。章の最後の2〜3カットは場面の人に戻して締める（例「お弁当を3つ詰めていたあの朝が、谷のいちばん底だったのです。」）。章の終わりは「では、〇〇な人には、どんな特徴があるのでしょうか。」の問いでよい（すぐ次の章で答えるので、答えの先送りではない）。
3. 特徴の章（第2章から4〜6章。1章に1つの特徴）。各章の並び：
   1. 特徴の文：「1つ目の特徴は、〇〇です。」（2つ目・3つ目…と続ける）。〇〇は、行い・頭の中で起きていること・研究で分かったことで言う（例「眠っている間に、昼の出来事を片づけ直していること」）。「やさしすぎる」「頑張り屋」「繊細」のような人柄の点数にしない（§4 の内面に点をつけない）。
   2. あるある場面2〜4カット：その特徴が出る毎日の場面と、頭の中の一言（「あれ、鍵かけたかな」）。
   3. 研究を物語で：どこの大学の誰が（カタカナで）、何人に、何をしてもらって、何が分かったか。驚く数字を1〜3個（「3人に2人」「190回」「24時間」）。facts.json の may_say にある数字だけ。
   4. 二段目の驚き：「話はここで終わりません。」「本当に意外なのは、ここからです。」のような1文のあと、すぐに2つ目の発見（同じ研究の別の結果か、別の研究）。毎回同じ言い方にしない。
   5. 身近なたとえを1つ（例「閉じ忘れたスマホのアプリが、電池を使い続けるのと同じです。」）。
   6. 章の締めの1文：特徴を三人称で、研究で分かった傾向として言う（例「〇〇な人の頭の中では、眠っている間も、一日の片づけが起きやすいのです。」）。研究で調べた人（年代・条件）と言える範囲で言い、調べていない人に広げない。「必ず」「みんな」で言い切らない。研究は、その特徴の場面にいる人を調べた物を選ぶ（例：夜中に目が覚める特徴なら、夜中の眠りを調べた研究）。
   - 後ろの特徴ほど意外にする。いちばん驚く研究を最後の特徴の章に置き、そこを見どころ（§5 の peak）にする。
   - 例の人を出す時は「たとえば、こんな人を思い浮かべてください。」のように、想像の例と分かる形にする。本当にいる人・寄せられた声のように言わない。
4. チャンネルの紹介と登録の呼びかけ：まとめの中の、コメントの問いのあと・締めの挨拶の前に置く（競合と同じ）。真ん中（語りの30〜55%）の章と章の間に置いてもよい。特徴の章の途中には入れない。文は 001 の E01・E02 でよい（「このチャンネルでは、人の心と脳のふしぎを、研究をもとにお届けしています。」「続きが気になった方は、チャンネル登録と高評価で応援してもらえると励みになります。」）。
5. 暮らしの工夫の章（最後の本編の章）：暮らしで試せること3つ（「1つ目は〜」）。それぞれに研究を短く1つ。研究の言える範囲から外れる効果の約束はしない。
6. まとめ：「今回のお話を、ふり返ります。」→ 特徴を1つ1文で → 余韻の1〜2文（ことわざ・昔の人の言葉を1つ引いてよい。誰の言葉か確かな物だけ）→ コメントへの問い（「あなたは、いくつ当てはまりましたか？」「〇〇な時、あなたはどうしていますか？」に、答えの例を2つ「たとえば、〇〇、△△など」）→「コメントで教えてください。」→ 登録の呼びかけ（4 をここに置く時）→「見てくださって、ありがとうございました。」→「また次の動画で、お会いしましょう。」
- クイズ（「ここで問題です。」）は入れてもよい（2026-10-29 から必須ではない）。入れる時は特徴の章の研究の手前に1つ。
- 競合から写さない物（理由つき）：
  - 「あなたが〇〇なのは、△△だからではありません」の打ち消し：見る人の内面に点をつける言い方になる（§4）。「〇〇な人の頭の中では、△△が起きています」と、起きていることで言う。
  - 「最後まで見ていただければ」「最後に〇〇をお話しします」：答えの先送り（§4）。
  - 病気の話・医療機関の案内：収益化できない（§1）。
  - 「このチャンネルにも、こんな声が届いています」：作った声になる。

## §4 語りの決まり

- やさしい言葉で、1文に1つのこと。漢語・カタカナ語は言いかえる（「ネットワーク」→「つながり」など）。
- 研究は物語で話す（「〇〇大学の△△さんたちは、□人に、〜をしてもらいました。すると〜」）。大学の名前と研究者の名前は、特徴の章ごとに中心の研究を1回ずつ言ってよい（研究者はカタカナで）。「〜という研究があります。」「〜が分かりました。」だけの講義の言い方を3カット以上続けない。
- 研究の結果は「〜が分かりました」「研究者たちは〜と見ています」で、言い切りすぎない。観察研究（相関）を「〇〇すると△△になる」と言わない。
- 数字：驚く数字を、特徴の章ごとに1〜3個。耳で分かる形にする（「67%」より「3人に2人」でもよい）。facts.json の「言ってよい範囲」にない数字は書かない。
- 場面は、見る人の年代の毎日の暮らし（台所・こたつ・庭・縁側・スーパー・公民館・町内会・孫・夫・年賀状・電話。病院の場面は使わない）。若い人の職場の話は「若いころ」の思い出として出す。
- 見る人の内面に点をつけない（「頑張ってきた証」「自分を責めないで」「そのままでいい」は使わない）。特徴は人柄の点数ではなく、行い・頭の中で起きていること・研究の結果で言う。外に見える場面と研究の結果で話す。
- 時を決める言葉を使わない（「今夜」「今日は」）。「今回」「この動画」を使う。
- 記号：「──」「…」「※」「★」「→」は使わない。かぎかっこ「」は短い言葉の引用だけ。
- 毎回の決まった文は §3 にある物だけ（予告の文・「〇つ目の特徴は」・前提の章の終わりの問い・登録の呼びかけ・まとめの文）。それ以外のメタな文（「次の章では」「ここまで」）は書かない。
- 答えを先に延ばすだけの文は書かない（2026-10-28 本人の指摘。references/16 の6）：「最後に言います」「このあと発表します」「答えは最後の章で」「後半でお見せします」「最後まで見てください」の形。問いは出してよいが、引くのは中身で。check_psy_script.py が NG にする。

## §6 タイトルとサムネ（競合の伸びた題の型。2026-10-29 から）

- タイトル：「【心理学】」で始め、45〜65字（競合の伸びた30本の中央値は45.5字）。次の型のどれか（3案は型を変える。直近の回と同じ型を3回続けない）。
  - A「【心理学】〇〇な人の「意外な特徴」｜研究で分かる答えの一部」（例：【心理学】一日中家から出ない人の「意外な特徴」｜何もしない一日に、脳が取り戻しているもの）
  - B「【心理学】〇〇な人、実は〇〇です。」（例：夜中の同じ時間に目覚める人、実は〇〇です。〇〇は本編の答え）
  - C「【心理学】〇〇な人に共通するN個の特徴｜〜」
  - D「【心理学】〇〇する人の正体｜〜」
  - 〇〇な人は、見る人が「私のことだ」と思う行い・場面（家から出ない・夜中に目が覚める・人と会うと疲れる）。
  - かぎかっこの中の引きの言葉：意外な・隠れた・本当の・正体・恐ろしい。どれも本編にそれに見合う驚きの研究があって、本編で回収する時だけ使う。「恐ろしい」は、怖がらせる話ではなく「思っていたより大きなことが頭の中で起きている」研究がある回だけ。
  - 「〜理由」「〜わけ」で終わるだけの題（v3.4 までの形。伸びなかった）は主役にしない。
  - titles に3案（1番目が使う案。2・3番目は見張りの差し替え用）。
- サムネの文字（script.json の "thumb": {"lines": [...]}）：15_サムネの型 と PDCA_運用表_v2 §5 の決まり（2026-10-28 に2段へ変えた）。
  - 2段（2行）・合わせて11〜17字。上の段＝誰の話か（6〜10字。「〇〇な人は」）、下の段＝ひっかかり（4〜8字・いちばん大きい字）。字の大きさは make_thumb_psy.py が横幅に合わせて決める（下の段は横幅の9割ほど、上の段も6割以上）。
  - 白 #FFFFFF。大事な言葉1つだけ黄 #FFE234（2行のうち1か所）。下の段の外側には光が付く。
  - 言葉の型（競合の伸びたサムネ「実は／夜中3時に／目覚める人は」）：A案＝上「〇〇な人は」・下「実は〇〇」か「〇〇な特徴」。B案＝時刻・数字を入れる（「夜中3時に起きる人」）か、思い込みを打ち消す（「年のせい／じゃない」）。タイトルの言い直しにしない（同じ言葉は少なく）。
  - 打ち消すのは、わけの思い込み（年のせい・性格のせい）だけ。見る人の行いを「怠け・甘え・わがまま・弱さ」ではないと打ち消して許す言い方は、§4 の「内面に点をつけない」に当たるので、タイトル・サムネ・ショートの題でも使わない（2026-10-28 002 で残った）。
  - 形：{"lines": [[["家から出ない人は", "#FFFFFF"]], [["実は", "#FFFFFF"], ["回復中", "#FFE234"]]]}（1行は [文字, 色] の並び。前の版の3行の形も読める：2・3行目をつないで下の段にする）
  - サムネを作ったあと、道具が点検を出す（いちばん大きい字の横幅70%以上・上の段60%以上・字の面積30〜60%・行数4まで・色を変えた語・字のない中段の高さ）。NG が出たら言葉を短くして作り直す。横320pxで読めるかは --check が見る。
  - B案（"lines_b"。同じ形）も書く。A案と言葉の型を変える。公開の後にクリック率が低い時、見張り（watch.py）がタイトルの2番目の案と一緒に差し替える。

## §8 研究（facts.json）

- 書く AI が WebSearch・WebFetch で調べて facts.json に書く。ネタ帳の hint は手がかりで、合わない時は別の研究を選んでよい。特徴の章ごとに中心の研究が1つ要るので、特徴の数に合わせて選ぶ。
- 1本に研究を5〜9個。どれも査読のある論文か、大学・学会の公式の解説。論文は DOI を書く（無い時は PubMed・大学のページの URL）。
- 驚く数字（人数・割合・回数・時間）は、論文の抄録か公式の解説で確かめた物だけを may_say に書く。台本で言う大学の名前と研究者の名前も may_say に書く。
- facts.json の形：
  {"checked": "2026-10-27", "studies": [{"key": "S1", "cite": "Fung, Carstensen & Lutz (1999) Psychology and Aging", "doi": "10.1037/0882-7974.14.4.595", "url": "https://...", "first_author": "Fung", "year": 1999, "finding": "分かったこと（2〜4文）", "may_say": "台本で言ってよい範囲（大学・研究者・人数・数字も）", "kind": "実験|観察|総説"}], "not_say": ["言わないこと"]}
- 研究の結果を言うカットには "study": "S1" をつける（台本ゲートが facts.json と照らす）。card の source は、その研究の cite と同じ著者・年にする。
- 同じ研究を、直近の回で中心に使っていたら、中心にしない（脇で1回触れるのはよい）。

## §10 ショート（script.json の "short"。2026-10-27 から）

- 本編と同じ日に、本編の絵から作る。公開は見張りが、本編の公開のあとの 07:10・12:10・20:10 の空いた枠に順に予約する（1日3本まで）。
- 本数（2026-10-29 から）：特徴の章1つにつき1本、合わせて4本まで。1本目は "short"（いちばん驚く特徴）、2本目からは "extra_shorts"（同じ形の並び・3本まで・驚く順）。どれも、その特徴の章の絵と研究だけで1つの話にする。題・S01 の問い・上の帯の字は1本ずつ別にする。長尺は週5本なので、ショートは週20本前後になる。
- 形：{"title": "【心理学】〜（60字まで）", "lines": [[["白の字", "#FFFFFF"], ["黄の字", "#FFE234"]]], "desc": "2〜3行", "cuts": [{"id": "S01", "narration": "...", "from": "本編のカットの id"}]}
- 題は §6 の型（「〇〇な人、実は〇〇」「〇〇な人の意外な特徴」）でよい。
- 長さ：語り 180〜290字（句読点を除く）・5〜11カット・1カット40字まで・id は S01 から順に。約35〜57秒。60秒を超えたら作り直し。
- 組み立て：
  1. S01：毎日の場面を問いで（「〇〇な人、いませんか？」「〜のは、なぜでしょうか？」）。from は本編で motion を付けたカット（ショートの1カット目は動く絵。2026-10-28。references/16 の2）。
  2. 本編の場面を1〜2カット。
  3. 研究を2〜3カット（"study" をつける。may_say の範囲だけ。驚く数字を1つ入れる）。
  4. 最後から2つ目のカットは、答えの一歩手前で止める。いちばん面白い所（答えの一歩手前）のカットに "peak": true を書き、from を本編で motion を付けたカットにする（S01 と最後のカットには付けない。references/16 の4）。
  5. 最後のカットは決まった文「続きは、本編の動画でお話ししています。」
- 語り：§4 と同じ決まり。本編を見ていない人にも分かる1つの話にする。「答えは本編で」「このあと」のような先送りの文は書かない（最後の決まった文だけは例外）。
- from：本編の語りのあるカット（card と THUMB は使わない）。主役が出るカットと動かす絵のカットを優先。同じ from は2回まで。
- 上の帯の字（lines）：1〜2行・1行12字まで。白と、大事な言葉1つだけ黄 #FFE234。
- 書いたら python -X utf8 pipeline/make_short_psy.py <作業フォルダ> --check を回し、NG が0件になるまで直す。
