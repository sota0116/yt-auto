## §3 組み立て（001 の順番）

1. つかみ（A01〜A05・語りの0〜2%）

   - A04：「今回は、〇〇を、心理学の研究から見ていきます。」の1文（つかみで1回だけ許す決まった文）。
   - A05：「最後に、〇〇も、お話しします。」（持ち帰りの予告）。〇〇には持ち帰れる中身を具体的に書く（「夜の電話で、話が弾むコツ」など）。中身の無い「最後に大事なことを」にしない。

4. 語りの40〜50%の所：チャンネルの紹介1文＋登録の呼びかけ1文（001 の E01・E02 と同じ文でよい：「このチャンネルでは、人の心と脳のふしぎを、研究をもとにお届けしています。」「続きが気になった方は、チャンネル登録と高評価で応援してもらえると励みになります。」）。
5. 第4〜5章：別の研究で同じ話を裏から確かめる（記憶・注意・もめごと・長い追跡など）。
6. 最後の本編の章：暮らしで試せること3つ（「1つ目は〜」）。研究の言える範囲から外れる効果の約束はしない。

## §4 語りの決まり

- やさしい言葉で、1文に1つのこと。漢語・カタカナ語は言いかえる（「ネットワーク」→「つながり」など）。研究者の名前は、中心の研究の人だけ1〜2人、1回ずつ言ってよい（カタカナで）。
- 研究を言う時は「〜という研究があります」「〜が分かりました」「研究者たちは〜と見ています」で、言い切りすぎない。観察研究（相関）を「〇〇すると△△になる」と言わない。
- 数字：年・人数・割合は、その研究の結論に要る物だけ、1章に1〜2個まで。facts.json の「言ってよい範囲」にない数字は書かない。
- 場面は、見る人の年代の毎日の暮らし（台所・こたつ・庭・縁側・スーパー・公民館・町内会・孫・夫・年賀状・電話。病院の場面は使わない）。若い人の職場の話は「若いころ」の思い出として出す。
- 見る人の内面に点をつけない（「頑張ってきた証」「自分を責めないで」「そのままでいい」は使わない）。外に見える場面と研究の結果で話す。
- 時を決める言葉を使わない（「今夜」「今日は」）。「今回」「この動画」を使う。
- 記号：「──」「…」「※」「★」「→」は使わない。かぎかっこ「」は短い言葉の引用だけ。
- 毎回の決まった文は §3 にある物だけ。それ以外のメタな文（「次の章では」「ここまで」）は書かない。
- 答えを先に延ばすだけの文は書かない（2026-10-28 本人の指摘。references/16 の6）：「最後に言います」「このあと発表します」「答えは最後の章で」「後半でお見せします」「最後まで見てください」の形。問いは出してよいが、引くのは中身で。check_psy_script.py が NG にする。

## §5 絵

- image は日本語で場面を1〜2文。

  - 紙・本・手帳・画面には「（文字は読めない）」と書く。研究者の顔・実在の場所の看板は描かない。
- 同じ絵の使い回し："same_as": "前のカットの id"。続けて同じ絵を見せたい時だけ。全カットの12%まで。
- 動かす絵："motion": true のカットは、Lovart の Kling で5秒の動く絵にする（無料の時だけ・時間内にできた分だけ）。つかみ（A）と第1章の頭の主役の場面を中心に、主役が出る大事な場面に合計25〜35カット。動きが小さく済む場面（主役がうなずく・振り向く・湯気・葉のゆれ）にする。物だけの絵でも湯気・光のゆれが映える場面ならよい（001 は33カット）。どの章（つかみ以外の本編・まとめ）にも motion のカットを1つ以上置く（2026-10-28 本人の指摘「紙芝居」。references/16 の2。点検が NG にする。完成した動画で動く絵が0カットなら、完成動画ゲート gate_video.py が落とす）。

  - 表の形：{"head": "見出し", "rows": [["条件", "結果"], ...], "source": "..."}（3行まで。前後・年代の比べに使う）
  - card のカットにも image は書く（使わないが、絵ゲートの点検で場面が分かるように）。
- 大事な言葉："label": "16字以内"（画面の左上に大きく出す。18字を超えると NG）。1章に3〜4個。とくに大事な所は "strong": true（1本に2〜3個）。card のカットの label は画面に出ない（カードに要点を書くため）。

- 絵の画質（2026-10-28 本人の指摘。references/16 の1）：make_images_lovart.py は Lovart の絵を縮めずに残す（2752×1536 なら縦横の比だけ16:9に切って 2730×1536。1920×1080より小さい時だけ大きくする）。

  - 主役はしずく（クリーム色・若草色のマフラー）のまま。顔に、その回に合う気持ちを1つはっきり出す（驚き＝目を大きく・口を丸く、不安＝眉を下げて汗のしずく、困惑＝首をかしげて「？」の形の線、ほっとした顔＝目を細めて頬を赤く）。image に気持ちとその理由になる場面を書く（例：「届いたはがきを手に、眉を下げて首をかしげる主役」）。点の目と小さな口の画風は変えない。

  - その回の場面がひと目で分かる小物を1つ持たせる。

## §6 タイトルとサムネ

- タイトル：「【心理学】」で始め、60〜80字。毎日の場面＋「〜理由」「〜わけ」＋「｜」のあとに研究で分かる答えの一部。titles に3案（1番目が使う案。2・3番目は見張りの差し替え用）。
- サムネの文字（script.json の "thumb": {"lines": [...]}）：15_サムネの型 と PDCA_運用表_v2 §5 の決まり（2026-10-28 に2段へ変えた）。
  - 2段（2行）・合わせて11〜17字。上の段＝何の話か（7〜9字・毎日の場面）、下の段＝答え・ひっかかり（5〜8字・いちばん大きい字）。字の大きさは make_thumb_psy.py が横幅に合わせて決める（下の段は横幅の9割ほど、上の段も6割以上）。
  - 白 #FFFFFF。大事な言葉1つだけ黄 #FFE234（2行のうち1か所）。下の段の外側には光が付く。
  - 言葉の型：思い込みを打ち消す（「年のせい／じゃない」）か、「実は〇〇な人は」で毎日の場面を指す。タイトルの言い直しにしない（同じ言葉は少なく）。
  - 打ち消すのは、わけの思い込み（年のせい・性格のせい）だけ。見る人の行いを「怠け・甘え・わがまま・弱さ」ではないと打ち消して許す言い方は、§4 の「内面に点をつけない」に当たるので、タイトル・サムネ・ショートの題でも使わない（2026-10-28 002 で残った）。
  - 形：{"lines": [[["友だちが減ったのは", "#FFFFFF"]], [["年のせい", "#FFE234"], ["じゃない", "#FFFFFF"]]]}（1行は [文字, 色] の並び。前の版の3行の形も読める：2・3行目をつないで下の段にする）
  - サムネを作ったあと、道具が点検を出す（いちばん大きい字の横幅70%以上・上の段60%以上・字の面積30〜60%・行数4まで・色を変えた語・字のない中段の高さ）。NG が出たら言葉を短くして作り直す。横320pxで読めるかは --check が見る。
  - B案（"lines_b"。同じ形）も書く。A案と言葉の型を変える（A が打ち消しなら B は「実は〇〇な人は」）。公開の後にクリック率が低い時、見張り（watch.py）がタイトルの2番目の案と一緒に差し替える。

## §8 研究（facts.json）

- 書く AI が WebSearch・WebFetch で調べて facts.json に書く。ネタ帳の hint は手がかりで、合わない時は別の研究を選んでよい。
- 1本に研究を5〜9個。どれも査読のある論文か、大学・学会の公式の解説。論文は DOI を書く（無い時は PubMed・大学のページの URL）。
- facts.json の形：
  {"checked": "2026-10-27", "studies": [{"key": "S1", "cite": "Fung, Carstensen & Lutz (1999) Psychology and Aging", "doi": "10.1037/0882-7974.14.4.595", "url": "https://...", "first_author": "Fung", "year": 1999, "finding": "分かったこと（2〜4文）", "may_say": "台本で言ってよい範囲", "kind": "実験|観察|総説"}], "not_say": ["言わないこと"]}

- 同じ研究を、直近の回で中心に使っていたら、中心にしない（脇で1回触れるのはよい）。

## §10 ショート（script.json の "short"。2026-10-27 から）

- 本編と同じ日に、本編の絵から作る。公開は本編の公開の次の日の 12:10（見張りが予約を入れる）。
- 形：{"title": "【心理学】〜（60字まで）", "lines": [[["白の字", "#FFFFFF"], ["黄の字", "#FFE234"]]], "desc": "2〜3行", "cuts": [{"id": "S01", "narration": "...", "from": "本編のカットの id"}]}
- 長さ：語り 180〜290字（句読点を除く）・5〜11カット・1カット40字まで・id は S01 から順に。約35〜57秒。60秒を超えたら作り直し。
- 組み立て：
  1. S01：毎日の場面の小さな謎を問いで（「〜のは、なぜでしょうか？」）。from は本編で motion を付けたカット（ショートの1カット目は動く絵。2026-10-28。references/16 の2）。
  2. 本編の場面を1〜2カット。
  3. 研究を2〜3カット（"study" をつける。may_say の範囲だけ）。
  4. 最後から2つ目のカットは、答えの一歩手前で止める。いちばん面白い所（答えの一歩手前）のカットに "peak": true を書き、from を本編で motion を付けたカットにする（S01 と最後のカットには付けない。references/16 の4）。
  5. 最後のカットは決まった文「続きは、本編の動画でお話ししています。」
- 語り：§4 と同じ決まり。本編を見ていない人にも分かる1つの話にする。「答えは本編で」「このあと」のような先送りの文は書かない（最後の決まった文だけは例外）。
- from：本編の語りのあるカット（card と THUMB は使わない）。主役が出るカットと動かす絵のカットを優先。同じ from は2回まで。
- 上の帯の字（lines）：1〜2行・1行12字まで。白と、大事な言葉1つだけ黄 #FFE234。
- 書いたら python -X utf8 pipeline/make_short_psy.py <作業フォルダ> --check を回し、NG が0件になるまで直す。

## §11 電子ゴミにしない・毎日1つ上げる（2026-10-28 から・全チャンネル共通）

- 次のどれかに当たる本編・ショートは出さない。当たらなくなるまで直す。

  3. ショートが本編を切っただけで、ショートとしての問い（§10 の S01）と、答えの手前の止めが無い
  4. 絵がセリフと合っていない・同じ絵が続く・字が切れる
