# しずくの心理学　毎日の制作の手順書 v2（2026-10-27・§6 サムネB案と §10 ショートを足した）

毎日の制作（GitHub Actions の run_daily.py psy）で、台本を書く AI と台本ゲートが読む決まりの正本。
1本目（001 会いたい人がしぼられていく理由・v3）を見本にして、記録.md・PDCA_運用表_v1／v2 の決まりを1つにまとめた。
見本：C:\yt-auto\channels\psy\golden\script_001.json（001 の台本を毎日の制作の形に直した物）・golden\facts_001.md（使った研究と言ってよい範囲）。

## §1 チャンネル

- 見る人：50〜70代の女性。夜ひとりの時間に、お茶を飲みながら耳で聞く。画面は時々見る。
- 中身：人づきあい・ひとりの時間・眠りと夜・幸せの心理を、心理学の研究から解説する。毎日の場面に起きていることのわけを話し、暮らしで試せることを持ち帰ってもらう。
- 語り手：名乗らない（参考6chの上位12本で名乗りは0/12。記録.md 2026-10-25）。声は VOICEVOX:No.7 読み聞かせ。
- 主役：しずく（クリーム色のしずく形の小さなキャラ、点の目、若草色のマフラー）。絵に出るだけで、声では呼ばない。
- 書かないこと：心の病気の診断・治し方・薬・病院（AI の語り手による医療の助言は収益化されない）、占い・スピの言葉、効果の約束。くわしくは §8 と 禁止表現.txt。

## §2 1本の形

- 長さ：語りの字数 4,900〜6,000字（句読点・かっこを除いて数える）。組み立てで声を1.28倍にするので、約16〜19分になる（001 は句読点を除いて 5,254字・17分1秒・309字/分）。
- カット：1カット1〜2文、20〜45字。全部で170〜220カット。
- カットの id：章ごとに英大文字1字（つかみ A、第1章 B、第2章 C …）＋2けたの番号（A01・B01）。あとから足したカットは B04b のように小文字をつける。
- 章：つかみ（A）のあとに本編6〜7章＋まとめ。章の頭のカットに "chapter": "章の名前（20字以内）" を書く。最後の章は「まとめ」。

## §3 組み立て（001 の順番）

1. つかみ（A01〜A05・語りの0〜2%）
   - A01〜A03：見る人の毎日の1場面を、短い文で2〜3カット。「〇〇なのに、〇〇」の小さな謎で始める（001：「年賀状を出す相手が、気づけば半分になっていた。」「それなのに、会いたい人の顔は、前よりはっきり浮かぶ。」）。
   - A04：「今回は、〇〇を、心理学の研究から見ていきます。」の1文（つかみで1回だけ許す決まった文）。
   - A05：「最後に、〇〇も、お話しします。」（持ち帰りの予告）。
2. 第1章：その場面の続きを、昔と今の対比で広げる。章の終わりに「その答えは、後半の研究でお見せします。」のような引きを1つ。
3. 第2〜3章：中心の研究（理論・実験）。実験は「何をした → 何が分かった」の順で、数字は細かく出さない。第2章か第3章の山場の手前に、クイズを1つ入れる（「ここで問題です。」→ 問い → 2択か3択 → 答えは次のカットから）。
4. 語りの40〜50%の所：チャンネルの紹介1文＋登録の呼びかけ1文（001 の E01・E02 と同じ文でよい：「このチャンネルでは、人の心と脳のふしぎを、研究をもとにお届けしています。」「続きが気になった方は、チャンネル登録と高評価で応援してもらえると励みになります。」）。
5. 第4〜5章：別の研究で同じ話を裏から確かめる（記憶・注意・もめごと・長い追跡など）。
6. 最後の本編の章：暮らしで試せること3つ（「1つ目は〜」）。研究の言える範囲から外れる効果の約束はしない。
7. まとめ：「今回のお話を、ふり返ります。」→ 章ごとに1〜2文 → コメントへの問い（I10〜I11：「あなたの〇〇は何ですか？」「コメントで教えてください。」＋1文）→「最後まで見てくださって、ありがとうございました。」→「また次の動画で、お会いしましょう。」

## §4 語りの決まり

- やさしい言葉で、1文に1つのこと。漢語・カタカナ語は言いかえる（「ネットワーク」→「つながり」など）。研究者の名前は、中心の研究の人だけ1〜2人、1回ずつ言ってよい（カタカナで）。
- 研究を言う時は「〜という研究があります」「〜が分かりました」「研究者たちは〜と見ています」で、言い切りすぎない。観察研究（相関）を「〇〇すると△△になる」と言わない。
- 数字：年・人数・割合は、その研究の結論に要る物だけ、1章に1〜2個まで。facts.json の「言ってよい範囲」にない数字は書かない。
- 場面は、見る人の年代の毎日の暮らし（台所・こたつ・庭・縁側・スーパー・公民館・町内会・孫・夫・年賀状・電話。病院の場面は使わない）。若い人の職場の話は「若いころ」の思い出として出す。
- 見る人の内面に点をつけない（「頑張ってきた証」「自分を責めないで」「そのままでいい」は使わない）。外に見える場面と研究の結果で話す。
- 時を決める言葉を使わない（「今夜」「今日は」）。「今回」「この動画」を使う。
- 記号：「──」「…」「※」「★」「→」は使わない。かぎかっこ「」は短い言葉の引用だけ。
- 毎回の決まった文は §3 にある物だけ。それ以外のメタな文（「次の章では」「ここまで」）は書かない。

## §5 絵

- 画風（script.json の style にそのまま書く）：「やわらかい絵本のような水彩画、淡いクリーム色・若草色・生成りの配色、あたたかい灯り。人物はすべて、点の目と小さな口だけの、しずく形のシンプルなキャラで描く」
- 描かない物（script.json の avoid）：「読める文字、写実的な人間、実在の人物の顔、白くて丸いキャラ、実在の企業や大学のロゴ、国旗、有名なキャラクターに似た顔、裸、血やけが」
- image は日本語で場面を1〜2文。
  - 主役が出るカットは、image に「主役（クリーム色のしずく形の小さなキャラ、点の目、若草色のマフラー）」と書き、カットに "chars": ["hero"] をつける。主役は1枚に1人だけ。
  - ほかのキャラは「色ちがいのしずく形のキャラ」（ピンク・水色・茶色・うす紫）。年配か若いかは老眼鏡・つえ・かばんなどの小物で表す。
  - 人もキャラもいない絵は、image の最後に「（人物は描かない）」と書き、"nobody": true をつける。物だけの絵は場面の絵の3割まで（001 は27%）。
  - 紙・本・手帳・画面には「（文字は読めない）」と書く。研究者の顔・実在の場所の看板は描かない。
- 同じ絵の使い回し："same_as": "前のカットの id"。続けて同じ絵を見せたい時だけ。全カットの12%まで。
- 動かす絵："motion": true のカットは、Lovart の Kling で5秒の動く絵にする（無料の時だけ・時間内にできた分だけ）。つかみ（A）と第1章の頭の主役の場面を中心に、主役が出る大事な場面に合計25〜35カット。動きが小さく済む場面（主役がうなずく・振り向く・湯気・葉のゆれ）にする。物だけの絵でも湯気・光のゆれが映える場面ならよい（001 は33カット）。
- 研究カード："card" をつけたカットは、絵の代わりに「主役＋要点＋出典」のカードを映す。5〜8枚。研究の結果を言うカットに置く。
  - 文の形：{"text": "1行目\n2行目\n3行目", "source": "著者 (年) 雑誌名"}（1行14字まで・3行まで）
  - 表の形：{"head": "見出し", "rows": [["条件", "結果"], ...], "source": "..."}（3行まで。前後・年代の比べに使う）
  - card のカットにも image は書く（使わないが、絵ゲートの点検で場面が分かるように）。
- 大事な言葉："label": "16字以内"（画面の左上に大きく出す。18字を超えると NG）。1章に3〜4個。とくに大事な所は "strong": true（1本に2〜3個）。card のカットの label は画面に出ない（カードに要点を書くため）。
- サムネの背景：cuts の最後に語りのないカット {"id": "THUMB", "image": "...", "chars": ["hero"]} を置き、script.json の "thumb_bg": "THUMB" にする。主役を画面の右3分の1に大きく、左半分は何もない明るい場所（文字を置く所）。その回の場面がひと目で分かる小物を1つ持たせる。

## §6 タイトルとサムネ

- タイトル：「【心理学】」で始め、60〜80字。毎日の場面＋「〜理由」「〜わけ」＋「｜」のあとに研究で分かる答えの一部。titles に3案（1番目が使う案。2・3番目は見張りの差し替え用）。
- サムネの文字（script.json の "thumb": {"lines": [...]}）：PDCA_運用表_v2 §5 の決まり。
  - 3行・合わせて11〜17字。1行目は短い前置き（9字前後）、2・3行目は大きい字（各5字前後）。
  - 白 #FFFFFF。大事な言葉1つだけ黄 #FFE234（3行のうち1か所）。
  - 言葉の型：思い込みを打ち消す（「年のせい／じゃない」）か、「実は〇〇な人は」で毎日の場面を指す。タイトルの言い直しにしない（同じ言葉は少なく）。
  - 形：{"lines": [[["友だちが減ったのは", "#FFFFFF"]], [["年のせい", "#FFE234"]], [["じゃない", "#FFFFFF"]]]}（1行は [文字, 色] の並び。1行の中で色を分けてよい）
  - B案（"lines_b"。同じ形）も書く。A案と言葉の型を変える（A が打ち消しなら B は「実は〇〇な人は」）。公開の後にクリック率が低い時、見張り（watch.py）がタイトルの2番目の案と一緒に差し替える。

## §8 研究（facts.json）

- 書く AI が WebSearch・WebFetch で調べて facts.json に書く。ネタ帳の hint は手がかりで、合わない時は別の研究を選んでよい。
- 1本に研究を5〜9個。どれも査読のある論文か、大学・学会の公式の解説。論文は DOI を書く（無い時は PubMed・大学のページの URL）。
- facts.json の形：
  {"checked": "2026-10-27", "studies": [{"key": "S1", "cite": "Fung, Carstensen & Lutz (1999) Psychology and Aging", "doi": "10.1037/0882-7974.14.4.595", "url": "https://...", "first_author": "Fung", "year": 1999, "finding": "分かったこと（2〜4文）", "may_say": "台本で言ってよい範囲", "kind": "実験|観察|総説"}], "not_say": ["言わないこと"]}
- 研究の結果を言うカットには "study": "S1" をつける（台本ゲートが facts.json と照らす）。card の source は、その研究の cite と同じ著者・年にする。
- 同じ研究を、直近の回で中心に使っていたら、中心にしない（脇で1回触れるのはよい）。

## §10 ショート（script.json の "short"。2026-10-27 から）

- 本編と同じ日に、本編の絵から作る。公開は本編の公開の次の日の 12:10（見張りが予約を入れる）。
- 形：{"title": "【心理学】〜（60字まで）", "lines": [[["白の字", "#FFFFFF"], ["黄の字", "#FFE234"]]], "desc": "2〜3行", "cuts": [{"id": "S01", "narration": "...", "from": "本編のカットの id"}]}
- 長さ：語り 180〜290字（句読点を除く）・5〜11カット・1カット40字まで・id は S01 から順に。約35〜57秒。60秒を超えたら作り直し。
- 組み立て：
  1. S01：毎日の場面の小さな謎を問いで（「〜のは、なぜでしょうか？」）。
  2. 本編の場面を1〜2カット。
  3. 研究を2〜3カット（"study" をつける。may_say の範囲だけ）。
  4. 最後から2つ目のカットは、答えの一歩手前で止める。
  5. 最後のカットは決まった文「続きは、本編の動画でお話ししています。」
- 語り：§4 と同じ決まり。本編を見ていない人にも分かる1つの話にする。
- from：本編の語りのあるカット（card と THUMB は使わない）。主役が出るカットと動かす絵のカットを優先。同じ from は2回まで。
- 上の帯の字（lines）：1〜2行・1行12字まで。白と、大事な言葉1つだけ黄 #FFE234。
- 書いたら python -X utf8 pipeline/make_short_psy.py <作業フォルダ> --check を回し、NG が0件になるまで直す。
