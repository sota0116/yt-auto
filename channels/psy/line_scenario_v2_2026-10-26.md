## 3. 結果と取扱説明書（6問目のすぐあとに、2通続けて送る）

### 気くばりのしずく
```
{name}さんは「気くばりのしずく」でした💧

人といる時は笑っていて、家に着いてから疲れが出るしずくです。

・集まりでは笑って話していたのに、家に着いたとたん、座りこんで動けなくなる。
・帰り道に、自分が言ったひとことを思い出して、別の言い方を考えている。
・誘いを断ったあと、返事が来るまで何度もスマホを見る。

夫婦の話し合いで、気持ちを顔に出さないようにしていた人は、話の中身をあとで思い出しにくかったという研究があります（Richards・Butler・Gross 2003年）。
顔に出さないようにしている間も、頭はそのために使われています。家に着いてから出る疲れには、その分も入っているのかもしれません。
```
```
気くばりのしずくの取扱説明書📝

1. 集まりで本当は言いたかったことを、紙に1行だけ書く。
2. 誘いの返事は「予定を見てから返すね」と言って、家に帰ってから決める。
3. 帰ったら、着がえてお茶をいれるまでは、スマホを見ない☕
```

### 思い返しのしずく
```
{name}さんは「思い返しのしずく」でした💧

済んでいないことや前にあったことが、ひとりの時に浮かんでくるしずくです。

・夜中に目が覚めると、何年も前に言われたことを、言われた時のまま思い出す。
・通帳や病院の予約票を見たあと、この先のことを順番に考えはじめる。
・テレビを見ていても、昼間に気になったことが頭から離れない。

やり残した用事がある人は、別のことをしている間も、その用事が頭に浮かびやすかったという研究があります（Masicampo・Baumeister 2011年）。
その用事を「いつ、どうやるか」まで紙に書いた人は、用事が済んでいなくても、浮かんでくることが減りました。
```
```
思い返しのしずくの取扱説明書📝

1. 気になっていることを1つ紙に書き、横に「いつ、何をするか」を1行足す。決められない時は「水曜日に考える」でもかまいません。
2. 夜中に浮かんだことは、枕元のメモに一言だけ書いておく。
3. 通帳や病院の予約票を見るのは、日のあるうちにまとめて済ませる🌤
```

### ひとり時間のしずく
```
{name}さんは「ひとり時間のしずく」でした💧

ひとりで過ごすと、肩の力がぬけるしずくです。

・玄関の鍵を閉めてひとりになった時に、肩の力がぬける。
・人と会う約束は続けて入れず、間に何もない日をはさむ。
・ひとりで入る喫茶店や、ひとりで歩く道がある。

スマホも本も持たずに、しばらくひとりで座っていた人は、はしゃぐ気持ちも、いらいらや不安も、どちらもおだやかな方へ下がったという研究があります（Nguyen・Ryan・Deci 2018年）。
集まりのあとに、ひとりでお茶を飲みたくなるのも、このはたらきとつながっていそうです。
```
```
ひとり時間のしずくの取扱説明書📝

1. 人と会う予定を入れる時に、次の日は何も入れない日にしておく。
2. 明かりを1つ消してスマホを別の部屋に置き、少しの間だけ何もせずに座る。
3. 家族には「この時間はひとりで過ごすね」と先に伝えておく🍵
```

### がんばりのしずく
```
{name}さんは「がんばりのしずく」でした💧

家のことや仕事のことを、休みの日も頭の中で進めているしずくです。

・休みの日も、片づけや用事をしているうちに一日が終わる。
・体の具合が悪い日でも、家族の食事のしたくは自分でする。
・寝る前に、次の日にやることの順番を頭の中で並べている。

働く人に毎日の記録をつけてもらった研究では、仕事が終わってから仕事のことを頭から離せた日は、離せなかった日より、寝る前の疲れが少なく、気分もよかったそうです（Sonnentag・Bayer 2005年）。
家の用事でも、同じことが起きていそうです。
```
```
がんばりのしずくの取扱説明書📝

1. 次の日にやることを紙に書き出して、台所や玄関など、寝室の外に置く。
2. 書き出した用事のうち1つに線を引いて、その日はやらないと決める。
3. 具合が悪い日は出来合いのお惣菜にする、と家族と先に決めておく🍱
```
