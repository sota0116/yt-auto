## この環境の事情
- 作業の場所はリポジトリの直下。パスはここからの相対で書く。Linux（Ubuntu）・4コア・メモリ16GB。この実行が終わると、channels/{{CH}} と history 以外の手元のファイルは消える。
- 道具は `python -X utf8 <道具>` で動かす。VOICEVOX は 127.0.0.1:50021 で動いている。ffmpeg は `-threads 4` で動かす。
- 5分以上かかる処理（組み立て・音量）は、Bash の run_in_background か `nohup bash <作業フォルダの .sh> > <ログ> 2>&1 &` で動かし、ログを見て終わりを確かめる。前景で動かすなら timeout を 3000000 まで付けられる。.sh は作業フォルダに版つきで置く。裏で動かした処理が終わるまで、返答を終えない（返答を終えると実行が終わる）。
- Lovart・Kling は同時に頼むと Concurrent task limit・Rate limit で落ちる。道具のやり直しに任せ、1つの外部の待ちに30分以上かけない。取れなかった動く絵は止まった絵のまま進める。絵は1回の実行で終わらなければ _auto_run.md に残りを書いて終える（次の実行が同じコマンドで続きを受け取る）。
- 絵の偽の文字・数字・ロゴ・2コマ割れは、最後の検品ではなく絵を作った直後に見つける。作ったら数枚ずつの一覧画像にして見て、その場で作り直す（2回直らなければぼかすか、近い絵を使い回す）。
- 組み立ての後、音の大きさを測る。−14〜−16 LUFS に入っていなければ agent_shared/tools/loudnorm2.py（2回測る）をかける。
- 題は、同じチャンネルの過去の題の言い換えにしない（`python -X utf8 pipeline/agent_run.py title {{CH}} "題"` で 0.55 以上なら作り直す）。
