## yt-auto への生かし方（案。まだ組み込んでいない）

1. **モーションカードの強化**: hyperframes の registry（約450部品）から、タイトル・数字カウント・図表・転換の書き方を借りて motion_cards_spi.html に移す。借りるのは書き方だけで、hyperframes 本体は CI に入れない（版の固定・月1更新の方針を崩さないため）。
2. **決定的レンダリングの考え方**: hyperframes は「止めた timeline を1フレームずつシークして撮る」。今の playwright 撮影で動きがぶれる時は、同じやり方（`Date.now()` やシードなしの乱数を使わない、時間でシークする）に寄せる。
3. **点検**: カードの HTML を直した時は、chrome-devtools-mcp でコンソールエラーと表示を確認する。impeccable の `npx impeccable detect`（62ルール・決定的）はデザインの機械点検に使える。使う時は環境変数 `IMPECCABLE_NO_TELEMETRY=1` を付ける。

## 注意

- hyperframes のスキルは、開始時に `npx hyperframes events` で利用ログを送る作りになっている。送ってよいかは使う時に決める。
- hyperframes の checkout の中で `npx skills add ... --all` を実行しない（`skills/` が消えることがある。公式 CLAUDE.md の警告）。
- media-use スキルは入れていない（HeyGen の有料機能へ誘導するため）。

## 追記（2026-11-07）：GSAP と three.js を千年こよみ（spi）のカードに入れた

上の表で GSAP は「メモのみ」、three.js は「見送り」としていた。見直して、次の形で入れた（重い物は入れていない）。

### 入れたもの

- ライブラリは `pipeline/vendor_js/` に写しを置き、ネットに取りに行かない（CDN を使わないので、版が勝手に変わらない）
  - GSAP 3.14.2（`gsap-3.14.2.min.js`・`GSAP-NOTICE.txt`）
  - three.js r185（`three-r185/`・`Three-LICENSE.txt`）
- `pipeline/motion_cards_spi.html` v10（写し `motion_cards_spi_前_2026-11-07.html`）
  - 新しいカード `kinetic`：大きい字が1字ずつ落ちる（`style:"drop"`）／弾む（`style:"pop"`）
  - 新しいカード `count`：数字が数え上がる（`value`・`from`・`prefix`・`unit`・`decimals`）
  - 背景 `bg3d:"stars"`：金の粒の球と奥の星を、カードの後ろに薄く重ねる。付けたカードだけに出る
  - GSAP は「止めた timeline を draw(t) で seek する」形で使う。GSAP が読めない時は自前の動きで同じ並びに描く。three.js が動かない時は背景だけ飛ばしてカードは描く
- `pipeline/motion_cards_spi.py`：`@VENDOR@` を `vendor_js` の場所に置き換える
- `pipeline/check_spi_script.py`：型に kinetic・count を足し、形の検査と bg3d の値の検査を足した
- `pipeline/write_script_spi.py`：台本を書く時の説明に、kinetic・count・bg3d の使い方を足した（1本に2〜4枚まで・bg3d は山場か章の頭の1〜2枚だけ）
- 既存のカードの見た目は変えていない。新しいカードを使うかどうかは台本側が選ぶ

### 分かったこと

- GSAP は既定で translate3d を使う。そのままだと、kinetic のカードが描くたびにわずかに違う絵になった（Chrome が字を別の層で描く時機がずれるため、と推測）。`gsap.config({force3D:false})` を入れて、2回描いて同じ絵になることを確かめた
- three.js の背景は、粒の位置を `spec.seed`、回転を時間で決めるので、何度描いても同じ絵になった

### まだ確かめていないこと

- GitHub Actions（ubuntu）の Chrome で three.js（WebGL）が動くか。手元（Windows・Chrome 156）では `--disable-gpu` のままでも、ソフトウェア描画（SwiftShader）で WebGL が動いた。ubuntu でも同じ形で動く見込み（推測）。動かなかった時は背景が出ないだけでカードは描ける。その時は `--enable-unsafe-swiftshader` などの起動フラグを足して試す
