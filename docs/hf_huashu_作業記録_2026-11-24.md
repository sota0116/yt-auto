# SPI の HyperFrames 3D と比較カード

## HyperFrames 3D

- `script.json` で `hf_3d: true` を付けた章頭（`chapter` / `yt_chapter`）または山場（`peak`）から、語りのある先頭2カットを選ぶ。台本点検はフラグの型・配置・本数を検証する。台本には通常のカードも指定する。
- `build_long_spi.py` で通常カードと整音済みの声を準備したあと、`make_hf_spi.py` が作業フォルダ内の一時プロジェクトを描画する。単体実行は `python -X utf8 pipeline/make_hf_spi.py <作業フォルダ>` で、各カット8秒を使う。
- 既存パイロットの見出しと短い字幕を HTML エスケープして差し替え、尺に比例して登場時刻を調整する。ローカルの `assets/lib/` と HyperFrames 0.9.19 を使う。ソフトウェア GPU を指定し、テレメトリを無効にする。
- `images/_hf/<ID>.mp4` と入力ハッシュを保存する。ハッシュには描画後の HTML、テンプレート資産、CLI バージョンと GPU モードを含める。FFprobe で映像ストリームの尺を確認し、組み立て時は通常クリップと同じ形式・長さへ変換する。CLI 欠落、失敗、180秒のタイムアウト、変換失敗時は通常カードを使う。
- 日次 CI は SPI ジョブでだけ Node 22 と固定版を準備する。インストールは3分制限で、失敗時も残りの制作を続ける。導入判断に使った先行値は `bench_hyperframes.yml` の `ubuntu-latest`、software GPU、8.0秒カットのレンダー32.7秒。

## 比較カードと拍同期

- `chart_bar` は共通の単位で2〜5項目を比較する。値をリストで受け取り、見出し、ラベル、数値、最大値に対する横棒を描く。台本生成と点検に仕様を追加した。
- 比較カードは `draw(t)` で描画する。既存のテーマ変数と CSS を使用し、ローカル GSAP / three.js の読み込みと既存カードの描画関数を維持した。
- `build_long_spi.py <作業フォルダ> --beat-bpm 120 --beat-offset 0.24` で BPM と拍の位相を設定できる。BGM 先頭からの時間で拍を求め、BGM のループごとに位相を揃え、各カットへローカル時刻として渡す。カードの登場時刻から最寄りの拍が0.16秒以内の場合は登場をその拍に寄せ、棒を短く明るくする。直接描画する場合は `spec.beat` に秒の配列を指定する。省略時の比較カードは既定の時刻で順に出る。動画と音声の切り替え位置は従来の尺を使う。
- 参照した `huashu-motion` のコミットは `f4f38bfe295a3f768753857be9236cc3277c7dad`。MIT ライセンスを確認し、比較グラフの表示順序と、音楽先頭基準で拍位置を扱う設計を自前実装に反映した。カードは既存のローカル資産と標準 CSS/DOM で描く。[MIT ライセンス](https://github.com/alchaincyf/huashu-motion/blob/f4f38bfe295a3f768753857be9236cc3277c7dad/LICENSE)・[finance-chart の構成](https://github.com/alchaincyf/huashu-motion/blob/f4f38bfe295a3f768753857be9236cc3277c7dad/templates/finance-chart/template.json)・[拍の解析と表現](https://github.com/alchaincyf/huashu-motion/blob/f4f38bfe295a3f768753857be9236cc3277c7dad/cli/lib/beats.js)

## 検証結果

| 試験 | 結果 |
| --- | --- |
| Windows で HyperFrames 0.9.19 を単体実行 | software GPU で8.0秒のカットを1本書き出した |
| 長尺組み立ての合成音声による試験 | 整音後の声1.852秒に対して素材の映像は1.866667秒。30 fps の1フレーム以内で、3D を使った長尺出力が完成した |
| キャッシュとフォールバック | 同じ入力で再組み立てすると3Dキャッシュにヒット。見出しを変えて CLI を PATH から外すと、古い3D素材がある状態でも通常カードで長尺出力が完成した。タイムアウトと CLI の非ゼロ終了はモックで確認した |
| 既存 SPI 台本の回帰 | wip の 017、018、019 は変更前後とも NG 0件 |
| 比較カードを2回描画 | 同じ拍付きジョブを別々に実行し、両方ともエラー0。FFmpeg の `framemd5` で37フレームすべてが一致した |
| 拍付き長尺組み立て | 合成 BGM で120 BPM、位相0.24秒を指定して長尺出力が完成した。別途、2カットと BGM ループをまたぐ拍時刻を照合した |
| Python 構文と差分 | 変更した5本の `py_compile`、`git diff --check`、差分の UTF-8 と文字化けの点検に合格 |

変更後の日次 GitHub Actions と実際の番組 BGM での同期は未実行。Windows の試験では、既存の組み立て用ライブラリを元の作業ツリーから読み取り専用で参照し、合成音声と合成 BGM を使用した。
