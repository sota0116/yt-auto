# 学び（しずくの心理学）2026-11-09
週報が書く。台本の書き手は毎回読む。手順書とぶつかる時は手順書が勝つ。

## 長尺
- タイトルは「〜に共通するN個の特徴（こと）」の型（§6 の C）が、「〇〇な人の「意外な特徴」」の型（§6 の A）より再生が多い：C の2本は 002 683回（7日）・006 57回（72時間）、A の3本は 001 2回・003 7回・004 8回（どれも7日）。C の2本中2本が、A の3本のどれよりも多い。1番目の案を選ぶ時は C を先に考える（同じ型を3回続けない決まりの中で）。
- つかみで3割以上が離れる：再生が50回以上の4本（002・005・006・007）の4本中4本で「最初の30秒で30%以上が離脱」が出た。うち3本（002・005・006）は「1分の時点で残りが50%未満」も出た。1文目でこの回で何が分かるかを言い（§3-1）、毎日の場面は2〜4カットに収める。
- 研究の説明を並べた所が低い：台本ゲートの点がある6本（005〜010）の6本中6本で、直す所に「数字や実験の説明が並んで講義っぽい」が出た（005 E09・006 C06〜C14・007 C07〜C08・008 F05〜F10・009 D06〜D17・010 B07〜B09）。数字を1つに絞り、人の場面か、見る人への問いかけで語る。
- 1つの章で実験を続けて説明しない：009（D06〜D17 で実験3つ）と 010（C07〜C17 で実験2本）の2本で「中心の1本を人の様子で語り、もう1本は短い対比だけにする」と出た。
- 研究のあとは早く人の場面に戻る：007（値札を書く夜）・009（お隣さん）・010（朝の水やりの人）の3本で「研究の説明から、章の頭の人物の場面へ早く戻す」と出た。
- つかみの終わりに答えの形を一言：最初の30秒が7点の4本（005・008・009・010）は4本とも冒頭のカットに直す所が出て、4本とも「つかみの終わりに、答えの輪郭かひっくり返しの予感を一言だけ先に見せる」直し方だった。8点の2本（006・007）は冒頭の指摘が0本。§3 の1「意外な予告」の中でやる。
- 章の点：6本とも全部の章が6点以上（§9 の線）。いちばん低い章が6点だった回は6本中5本（007 だけ7点）。
- area：数字のある回は ひとりの時間2本（683回・57回）・人づきあい2本（8回・145回）、ほかは1本ずつ。2本の組どうしでも向きがそろわないので、まだ判定できない。

## ショート
- 上の帯の字に年の言葉が入った2本は1,000回を超えた：005 の1本目「14年前の自分を／明るく思い出す」1,281回（7日）、006 の3本目「年が上の人ほど／ひとりでもゆれにくい」1,007回（72時間）。年の言葉の無い13本は、いちばん多くて447回（2本中2本）。研究で調べた人の年代と合う時だけ、帯に年か年代の言葉を入れる（§3 の3の6）。
- つかみの文の形では差が無い：「〜のは、なぜでしょうか？」の8本は真ん中64回、「〜ありませんか？」の6本は真ん中87.5回（計算）。どちらの形にも1,000回を超えた回が1本ずつある。形は §10 の S01 のままでよい。
